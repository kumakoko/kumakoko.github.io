简介

常规设置选项卡 包含一组用于改进场景工作流程、控制地形对象的选项，还允许通过导入 OSM 或 KML 道路数据自动生成道路网络。

本页包含以下章节：

  • 场景设置
  • 道路类型
  • 连接预制体（交叉口、环岛和自定义预制体）
  • 默认材质
  • LOD 组
  • 地形管理
  • 导入道路数据

场景设置

  • Default Indent（默认缩进）：控制地形变形。默认值基于地形的 heightmapscale（尺寸与高度图分辨率之比），以确保根据道路和交叉口形状准确地平整地形。可选地增大这些值。Indent 值表示从道路边缘向外延伸到地形点的距离，该地形点将被平整到与道路在该点相同的高度，以保证最佳的地形变形效果。此值可以按标记逐个调整，但不能低于场景最小缩进值。不同的道路类型也可以设置不同的默认缩进值。
  • Default Surrounding（默认环绕）：默认环绕值表示在缩进位置处地形高度被平整到当前地形高度的距离。
  • Max Indent/Surrounding（最大缩进/环绕）：此值将用作所选标记的缩进/环绕滑块控件的最大值。
  • EasyRoads3D Layer（EasyRoads3D 图层）：默认情况下 EasyRoads3D 内部使用图层 31 进行后台操作，可以在此处更改。
  • Build Side Objects in Edit Mode（在编辑模式下构建侧边对象）：如果您更希望仅在构建模式下构建实际的侧边对象游戏对象，可以关闭此选项。
  • Use Light Probes（使用光照探针）：这将切换生成的道路网格渲染器上的"使用光照探针"选项。
  • Enable Back to Edit Mode without Terrain Restore（允许返回编辑模式而不恢复地形）：这是根据要求添加的，切换回编辑模式时，地形将不会恢复到切换到构建模式之前的原始状态。请谨慎使用！

场景视图设置

  • Highlight Selected Road（高亮所选道路）：高亮显示所选道路。在编辑模式下，当道路部分被地形覆盖时，这有助于在丘陵地区可视化道路。
  • Highlight Indents（高亮缩进区）：高亮显示缩进区域，即被平整到与道路相同高度的地形区域。
  • Highlight Surrounds（高亮环绕区）：高亮显示地形区域，在该区域上高度从道路高度逐渐过渡到原始地形高度。
  • Hide White Surfaces（隐藏白色表面）：隐藏道路和连接对象周围的白色表面。根据道路着色器的不同，这些白色表面可能会透过道路渲染出来。可以通过将 /Assets/EasyRoads3D/Resources/Materials/surfaceMaterial 上的 Offset 值向 0 减小来调整。
  • Enable Side Object Handles（启用侧边对象手柄）：在场景视图中显示手柄，例如用于控制侧边对象的起始和结束偏移。也可以使用 H 键。
  • Display Critical Areas（显示关键区域）：Unity 地形对象以 0 到 1 之间的小数存储地形高度数据，因此无法应用负高度值。接近或低于 0 值的部分将以红色手柄显示。这可以用来快速复查这些关键区域，确保地形不会穿透道路。
  • Only Display Markers Selected Road（仅显示所选道路的标记）：选中道路对象时，仅显示所选道路的蓝色标记。
  • Marker Handle Size（标记手柄大小）：控制场景视图中蓝色标记手柄的大小。
  • Marker Display Distance（标记显示距离）：控制显示手柄的最大距离。
  • Exclude Locked Objects（排除已锁定对象）：开启后，已锁定的对象将不显示标记手柄。
  • Mesh Terrain（网格地形）：或者，您可以使用网格地形代替 Unity 地形对象。网格地形不会根据道路形状变形。
  • Global Grid（全局网格）[Pro]：道路标记和连接预制体将吸附到网格，这对于城市或城镇环境很有用。
    • Grid Cell Size（网格单元大小）：单元大小
    • Grid Display Size（网格显示大小）：网格的可视化大小，焦点为窗口中心
    • Grid Rotation（网格旋转）：全局旋转
    • Grid Color（网格颜色）：网格单元轮廓的颜色
    • Local Grids（局部网格）：可以创建局部网格。当场景中需要不同的网格方向（旋转）或单元大小时很有用，控件与全局网格相同。
  • Scene Objects Control（场景对象控制）：默认情况下，Unity 会在点击场景中的对象时选中它。为了在添加标记或选择道路/交叉口对象时保持道路网络处于选中状态，对地形的点击事件会被拦截。其他大型对象（如水面）可能会干扰，它们在被点击时会被选中。可选地，可以通过从层级窗口拖放到"Add Object"槽中来添加此类对象。与地形对象一样，双击仍然会选中该对象。
  • Refresh Road Network（刷新道路网络）：重建并清理道路网络。

道路类型 [Pro]

特别是在构建包含不同道路类型的复杂道路网络时，建议在场景中实际构建道路之前设置道路预设。这些预设在向场景中添加新道路或设置交叉口/连接对象时可用，这是确保道路类型外观一致并与关联的交叉口类型匹配的简便方法。EasyRoads3D 道路类型也可以链接到 OSM 道路类型。

大多数属性与场景中道路对象的属性相同。其他控件说明如下。

  • Add New Road Type（添加新道路类型）：创建新的道路类型，新类型将自动被选中，您可以设置道路类型名称、宽度和材质。
  • Add Project Road Types（添加项目道路类型）：场景道路类型也存储在项目道路类型列表中，这样您可以跨场景重用道路类型。此按钮显示所有项目道路类型；场景中已有的道路类型将被禁用。
  • Manage Project Road Types（管理项目道路类型）：列出所有项目道路类型，允许您删除旧的、未使用的道路类型。注意，如果已删除的道路类型仍存在于某个场景中，它们将再次被添加。
  • Import Road Types（导入道路类型）：打开窗口以从另一个项目导入道路类型。
  • Export Road Types（导出道路类型）：打开窗口以导出道路类型，以便在另一个项目中使用。
  • Road Types（道路类型）：此下拉菜单列出场景中所有可用的道路类型。
  • Duplicate Road Type（复制道路类型）：创建道路类型的副本，便于快速创建具有几乎相同设置的新道路类型。
  • Remove Selected Road Type（移除所选道路类型）：从场景中移除所选道路类型，它仍保留在项目道路类型中。

主要设置：

  • Road Type Name（道路类型名称）：下拉菜单中所选道路类型的名称。
  • Road Width（道路宽度）：道路宽度。
  • Sub Segments（子分段）：控制细分。注意，动态内置交叉口尚不支持子分段。为了在道路网络中使用此功能，可以将带子分段的道路连接到 I 连接器，I 连接器另一端的道路可以连接到内置交叉口。
  • Default Vertex Color（默认顶点颜色）：此道路类型的默认顶点颜色，可按标记调整，例如可在自定义着色器中用于道路纹理过渡。

道路细节：

  • Resolution（分辨率）：以米为单位的几何分辨率。
  • Angle Threshold（角度阈值）：可用于优化道路几何形状，同时保持弯道细节。尝试约 5 的值，并将道路分辨率提高到 10 或 20，顶点/三角形数量将显著下降。
  • Bumpiness Y Offset（起伏 Y 偏移）：道路的平滑度，可通过最小/最大值控制。
  • Bumpiness Distance（起伏距离）：距离，可通过最小/最大值控制。
  • Random Tilting Angle（随机倾斜角）：为道路添加额外倾斜，可通过最小/最大值控制。
  • Tilting Distance（倾斜距离）：倾斜发生的距离。
  • Follow terrain Contours（跟随地形轮廓）：道路将自动调整以适应地形形状，这将大大加快工作流程，因为需要的标记更少。
  • Contour Threshold（轮廓阈值）：值越低，道路越贴合地形形状；高速公路等道路使用更高值。

材质：

  • UV Tiling（UV 平铺）：所用纹理的平铺大小，可按标记调整，例如可在自定义着色器中用于道路纹理过渡。
  • Additional UV Data（额外 UV 数据）：可选地，可以在 UV4 中存储更多 UV 数据，这可以是与地形边界匹配的数据，或基于指定距离的额外细节。该距离将根据道路距离重新计算，以便像主 UV 一样对这些 UV 进行限制。
  • Road Material（道路材质）：道路材质。下拉菜单列出 /EasyRoads3D/Resources/Materials/Roads 中的所有材质，可用于快速分配其他材质。
  • Connection Material（连接材质）：指动态连接对象上的连接。当为该特定连接选择此道路类型时，连接材质将自动更新。
  • Create New Connection Prefab（创建新连接预制体）：为所选道路类型自动生成新的动态预制体。
  • Physics Materials（物理材质）：此道路类型默认应分配的物理材质。

对象设置：

  • Layer（图层）：此道路类型的默认图层。
  • Tag（标签）：此道路类型的默认标签。
  • Static（静态）：勾选此复选框以将此类型的道路标记为静态。
  • Cast Shadows（投射阴影）：对象将投射阴影。
  • Terrain Deformation（地形变形）：可用于关闭此特定道路的地形变形，例如用作桥段的道路类型。
  • Default Indent（默认缩进）：此道路类型的默认缩进距离。
  • Default Surrounding（默认环绕）：此道路类型的默认环绕距离。

地形 Splatmap 烘焙：

可选地，道路形状可以烘焙到地形 splatmap 中，这是一种以自然方式将道路与地形混合的有效方法。以下选项在上方"地形变形"激活时可见。

  • Activate（激活）：为此道路激活地形 splatmap 混合。
  • Splatmap Texture（Splatmap 纹理）：列出所有可用的地形 splat map 纹理，选择要使用的纹理。
  • Expand（扩展）：增大道路形状的大小。
  • Smooth Level（平滑级别）：将所选纹理与原始地形 splatmap 逐渐混合。
  • Opacity（不透明度）：设置道路形状在地形 splatmap 中的强度。

起始/结束贴花：

在这里，我们可以添加将在道路起点和终点自动随机插入的预制体。随机选择的贴花始终可以在所选道路的主要道路设置中手动更新。

  • Add New Decal Object（添加新贴花对象）：将预制体拖放到此槽后，将出现额外选项。
    • Priority（优先级）：可用于让某些贴花比其他贴花出现得更频繁。
    • Position（位置）：此贴花用于道路起点、终点还是两者。
    • Scale（缩放）：贴花将相对于道路宽度重新缩放，缩放值可用于相对于此宽度缩放贴花。
    • Road Section Width（道路段宽度）：默认为道路宽度，但自定义预制体可能将人行道作为形状的一部分，在这种情况下可以在此输入实际道路宽度。
    • Height Offset（高度偏移）：预制体在道路上方的距离。
    • End Rotation（终点旋转）：当贴花同时用于道路起点和终点且方向应翻转时，此设置很有用；值 180 即可实现翻转。

侧边对象：

可以为道路类型激活侧边对象，这些侧边对象将为新实例自动激活。对于特定道路不需要侧边对象时，仍可以为该道路停用侧边对象。

  • Is Side Object（是侧边对象）：开启后不会创建实际的道路网格。这种"道路"类型可用于创建其他即用型对象，例如基于侧边对象的围栏——通过为此"道路"类型激活特定侧边对象。此功能也用于演示项目中的河流示例。

Active Side Objects（活动侧边对象）：

此处列出所有可用的侧边对象。激活侧边对象后，将出现一个折叠菜单，其中包含道路特定控件，这些控件也将在所有道路实例上可用。默认情况下，值继承自侧边对象管理器中的设置，在此处可以按道路类型进行微调。

按钮：

  • Create Snap Connector（创建吸附连接器）：在 /Assets/EasyRoads3D/prefab sources/snap connectors/ 中创建吸附连接器预制体。吸附连接器预制体可以附加到场景中的任何其他预制体上，此类型的道路/侧边对象可以快速附加到这些预制体，或者可以从预制体拉出新的道路/侧边对象。想象一下中央墙柱，多个墙侧边对象可以连接到它；将带有特定墙侧边对象自动激活的吸附连接器添加到墙柱预制体上，在场景中可以拉出新墙，现有墙可以快速附加到柱子上并与墙柱中心精确对齐。对于道路，想象一下带车道的房屋，将吸附连接器附加到车库门上，吸附车道道路对象，它将立即与车库门对齐。
  • Update Scene Instances（更新场景实例）：更新场景中与此道路类型匹配的所有道路实例和交叉口。

交叉口/连接预制体 [Pro]

EasyRoads3D 支持两种创建交叉口的系统，通常称为"连接预制体"，因为这类对象不一定必须是交叉口，也可以是基于网格的人行道预制体等。主要系统是动态预制体系统，这些是内置的可自定义连接预制体。第二个非常强大的系统是自定义网格预制体系统，您可以用它将自己的模型转换为连接预制体。您可以使用它进一步自定义道路网络，同时仍利用 EasyRoads3D 的场景工作流程。

动态交叉口预制体

动态交叉口系统目前支持创建新的标准 X 型、T 型交叉口和环岛预制体。当场景中有许多相似类型的交叉口时，这特别有用。通过先创建预制体，该预制体可以在场景中重复使用，而无需每次都自定义；仍可以在场景中创建此预制体实例的变体。

这些动态预制体将存储在：/Assets/EasyRoads3D/Resources/dynamic prefabs

新创建道路类型的动态 X 和 T 连接预制体可以从道路类型部分自动创建，或在本节中创建：

  1. 在"New Prefab Name"（新预制体名称）文本字段中输入新交叉口预制体的名称。
  2. 从下拉菜单中选择要创建的交叉口预设类型：交叉口或环岛。您也可以通过从 Create Copy of（创建副本）下拉菜单中选择现有预制体，从现有预制体创建新预制体，这对于快速创建带有变体的预制体很有用。
  3. 点击 Create（创建）或 Create New Prefab（创建新预制体）按钮（如果创建现有预制体的副本）。这将在上述文件夹中创建新预制体。

在此阶段，可以在 Inspector > Open Prefab 中打开新预制体进行编辑。

注意： 新创建道路类型的动态 X 和 T 连接预制体可以从道路类型部分快速创建，新连接预制体将继承所选道路类型的设置。

自定义交叉口

从现有预制体复制

如果要基于 EasyRoads3D 自带的预制体之一或基于之前创建的交叉口预制体创建新预制体，请使用此选项。

常规设置

  • Crossing Layout（交叉口布局）：控制交叉口的几何结构和样式。目前仅实现了 X 形，其他选项将后续添加。
  • T Crossing（T 型交叉口）：创建 T 形交叉口。
    • Resolution Straight Side（直边分辨率）：T 型交叉口直边段的几何分辨率。
  • Swap Turn（交换转弯）：通过此按钮可以控制另一条道路连接到左侧还是右侧。
  • Activate Bending（激活弯曲）：支持 T 型交叉口上的小角度弯曲。
  • Include Sidewalks（包含人行道）：此交叉口默认激活人行道，这也会激活下方的人行道设置。
  • Planar UVs（平面 UV）：生成平面 UV，而不是相对于连接方向的局部 UV，这对于铺装类交叉口样式可能很有用。
  • Terrain Deformation（地形变形）：地形将根据此交叉口的形状进行调整。

连接设置

连接设置指交叉口/连接各边的道路特征，每条边都可以有自己特定的特征。

  • Connection Setup（连接设置）：此下拉菜单包含三个选项。
    • Uniform Connections（统一连接）：所选道路设置将应用于所有四个连接。
    • Uniform Opposite Connections（统一对向连接）：前后连接共享相同设置，左右连接共享相同设置。
    • Unique Connection（独立连接）：每个连接都有自己特定的设置。
  • Select Road Type（选择道路类型）：这就是道路类型预设派上用场的地方。选择一个可用的道路预设来设置连接信息。关于未来功能，也强烈建议使用此工作流程，而不是手动调整下方单独设置（如宽度）。但是，对于场景中不会在其他地方重复使用的特定道路对象，仍可以这样做。注意，这些 v3.2 X 和 T 交叉口基于两节点道路形状，下拉菜单中仅列出具有 2 节点形状的道路类型；从自定义连接器创建的具有更复杂道路形状（超过 2 个节点）的道路类型不会列在下拉菜单中。
  • Connection Width（连接宽度）：连接的宽度。它将从所选道路类型继承，但可以为场景中外观不同的单个交叉口进行自定义。
  • Road Material（道路材质）：分配给连接到此连接的道路的材质。
  • Connection Material（连接材质）：此交叉口连接几何体上使用的材质。
  • UV Tiling（UV 平铺）：可用于控制此连接的 UV 平铺。

拐角设置

交叉口的每个拐角都可以有自己的属性，包括道路拐角形状和人行道。

  • Uniform Corners（统一拐角）：勾选后，拐角更改将应用于所有交叉口拐角。
  • Select Corner preset（选择拐角预设）：您可以将下方的拐角设置存储在 Inspector 中。这可用于快速将相同的拐角设置分配给所有交叉口/连接预制体中的其他拐角，只需从下拉菜单中选择所需预设。
  • Radius（半径）：圆角的大小。
  • Start Angle（起始角度）：当第二条道路吸附到主道路上时（例如泥土路连接到沥青路），此选项启用，这样您可以创建灵活的非 90 度圆角。
  • Rounding Segments（圆角分段）：用于获得圆角所需的几何分辨率。
  • Inner Segment Distance（内部分段距离）：控制内侧行道路顶点的距离，取决于您的道路纹理性质、标记厚度或道路两侧需要保留的其他设计元素。
  • Corner Preset Name（拐角预设名称）：如果要将当前设置存储为新预设，可以在此输入预设名称。
  • Save as Corner Preset（保存为拐角预设）：输入名称后点击此按钮将当前拐角设置存储为新预设。

人行道设置

当上方"常规设置"中的"Include Sidewalks"（包含人行道）激活时，以下控件将激活。

  • Select Sidewalk Preset（选择人行道预设）：与交叉口拐角一样，您可以从当前人行道设置创建预设，快速将相同的人行道设置分配给所有交叉口/连接预制体中的其他人行道。
  • Sidewalk Width（人行道宽度）：人行道的总宽度。
  • Curb Height（路缘高度）：人行道的高度。
  • Curb Width（路缘宽度）：为了在圆角中准确分配 UV，将生成额外的顶点。路缘的宽度取决于您的人行道纹理，您可以通过下方的人行道 UV 编辑器手动调整 UV。
  • Beveled Curb（斜切路缘）：为人行道生成更复杂的几何体。
    • Bevel Height（斜切高度）：额外分段的高度，保持为 0 将创建斜角形人行道。
    • Bevel Width（斜切宽度）：添加的斜向分段的宽度。
  • Outer Curb（外侧路缘）：在外侧添加额外三角形到道路高度。
  • Material（材质）：人行道材质。
  • Sidewalk Preset Name（人行道预设名称）：如果要将当前人行道设置存储为新的人行道预设，可以在此输入预设名称。
  • Save as Corner Preset（保存为拐角预设）：输入名称后点击此按钮将当前人行道设置存储为新预设。
  • Sidewalk UV Editor（人行道 UV 编辑器）：EasyRoads3D 将根据上述设置自动分配 UV，可选地可以微调。点击按钮将打开窗口，显示分配给所选材质的纹理。根据人行道几何体的复杂程度，您将在底部看到手柄，移动手柄将自动更新场景中的 UV。

场景中的连接手柄：

  • 每个交叉口拐角附近显示 3 个球形手柄。中间手柄控制该拐角整体的人行道渲染；外侧两个手柄控制是否将人行道添加到连接到这些交叉口的道路上。
  • 每个交叉口中心还有灰色手柄。点击灰色手柄后它将显示为白色，连接预制体将根据连接的道路方向对齐。

Inspector > UV Editor 按钮：

将出现 UV 纹理窗口，画布上显示所选道路纹理，可用于正确映射人行道 UV。水平拖动绿色手柄，UV 会在场景中直接更新。建议从连接左侧的人行道开始（朝向对象中心看）；如果右侧人行道匹配，之后可以点击 mirror（镜像）按钮，将左侧 UV 镜像到右侧。

如果某个手柄看起来无法拖动，取消选择后重新选择它！

自定义环岛

  • Roundabout Width（环岛宽度）：路段宽度。
  • Radius（半径）：从中心到路段中点的距离。
  • Resolution（分辨率）：环岛的几何分辨率。
  • UV Tiling（UV 平铺）：平铺强度。
  • Flip Connection UVs（翻转连接 UV）：将分布从朝向环岛反转为向外。
  • Connection Material（连接材质）：分配给连接的材质。
  • Inner Material（内部材质）：分配给环岛本身的材质。
  • Refresh Roundabout（刷新环岛）：重建环岛。
  • Distribute Connections Evenly（均匀分布连接）：在环岛周围均匀设置连接位置。
  • Add Connection（添加连接）：如果有足够空间，添加新连接。
  • Select Road Type（选择道路类型）：建议为连接分配道路类型，宽度和材质将自动调整。
  • Road Width（道路宽度）：手动设置宽度。
  • Connection Material（连接材质）：分配给连接段的材质。
  • Road Material（道路材质）：从此连接挤出的新道路对象使用的材质；分配道路类型时将从道路类型继承。
  • Position（位置）：环岛的位置，由与分辨率匹配的节点索引表示。
  • Left Rounding Radius（左圆角半径）：连接左侧的拐角半径。
  • Right Rounding Radius（右圆角半径）：连接右侧的拐角半径。
  • Rounding Segments（圆角分段）：拐角的分辨率。
  • Connection Length（连接长度）：连接的距离。
  • Delete Connection（删除连接）：从环岛移除连接。

以下是创建新环岛预制体的推荐步骤，特别是当使用比默认宽度 5 更大的道路宽度时：

  1. 删除连接，只保留一个连接。
  2. 将半径设置为一个安全的较大值，例如 20。
  3. 根据连接 1 的宽度，沿顺时针方向进一步移动 Position 值，使连接能很好地容纳，以适应下面的步骤 4。
  4. 为此连接选择道路类型，并将 Position 移回最低可能值。
  5. 按"Add Connection"（添加连接），为此连接选择道路类型，并将连接向连接 1 移动，为下一个连接腾出空间。
  6. 重复步骤 5。注意连接将在环岛周围重新分布；如果未插入连接，说明半径和当前连接位置不允许添加新连接，此时应重新定位连接和/或增大半径。
  7. 重复这些步骤，直到添加所有连接。
  8. 可选地，现在可以调整半径；当半径过小时，控制台将显示消息。
  9. 可选地，此时可以使用"Distribute Connections Evenly"（均匀分布连接）来重新排列环岛周围的连接。

注意： 蓝色手柄显示所选连接的边界；红色手柄显示所选连接可以重新定位的可用空间范围。

自定义交叉口预制体 [Pro]

自定义连接预制体是基于网格的预制体，准备在 EasyRoads3D 系统中使用。这些可以是您在建模应用程序中创建的独特模型，或适用于该系统的第三方资源。这样可以创建即用型连接/交叉口预制体，其工作方式与内置连接/交叉口预制体类似；可以挤出道路对象，也可以附加现有道路对象。该系统支持带子对象和子网格的预制体，目前将读取所有预制体网格数据。

  • 视频教程：http://youtu.be/yDUhBZg7tQM — 自定义道路网络 第 1 部分
  • 视频教程：http://youtu.be/qxeLHG7K9xQ — 自定义道路网络 第 2 部分

工作原理如下：

  1. 从 Inspector 中的工具栏选择 General Settings（常规设置）选项卡。
  2. 展开 Crossing / Connection Prefabs（交叉口/连接预制体）折叠菜单。
  3. 点击 Create New Custom Prefab（创建新自定义预制体），将出现自定义连接预制体窗口。

  1. 将您的网格对象从项目文件夹拖放到舞台上，它将被分配到左上方的 Source Object（源对象）槽中。
  2. 确保几何体以顶视图显示；如果不是，从 Trace（追踪）下拉菜单尝试不同的轴。
  3. Recalculate Normals（重新计算法线）：使用 Unity 的 Mesh.RecalculateNormals() 为网格分配法线（也用于生成的道路上），有助于实现从交叉口到道路的平滑过渡。
  4. Recalculate Tangents（重新计算切线）：当上方 Trace On（追踪开启）中应用了不同旋转时需要。
  5. 点击 Build Connection Prefab（构建连接预制体），将在 /Assets/EasyRoads3D/Resources/custom prefabs 文件夹中创建新的自定义交叉口预制体。
  6. 分配将连接到第一个连接所附加道路的顶点：按住 Shift 键，围绕这些顶点绘制矩形（Shift + 鼠标左键 + 拖动）。对于复杂网格，可以使用 Stage Rotation（舞台旋转）使所需顶点正好落在矩形内，所选顶点将以绿色高亮显示。
  7. 选择连接顶点后，系统将检查可用道路类型列表以匹配，并自动选择匹配的道路类型；有多个匹配项时可以更改。
  8. 点击 New Road Type（新道路类型）为此连接创建新道路类型（可选）。优点是此道路类型将为与该连接匹配的其他生成连接自动选择，还可以自动激活侧边对象到该道路类型。注意： 这确实需要道路形状数据，如果尚未为此连接选择节点，该按钮将被禁用。
  9. 从 Road Material（道路材质）下拉菜单中选择附加道路的道路材质，或通过将材质从资源文件夹拖放到下拉菜单下方的材质槽中手动分配。
  10. UV 编辑器窗口允许您对附加到此连接的道路上使用的 UV 布局进行更改。
  11. 如果希望连接与连接的道路角度对齐，可以设置额外的弯曲设置。使用 Distance（距离）和 Extend Bounds（扩展边界）设置弯曲强度和受影响的顶点，可通过 Deform Test（变形测试）滑块测试弯曲。[所有这些目前尚未激活]
  12. Top View（顶视图）/ Front View（前视图）将在以顶视图显示整个预制体和以前视图显示所选连接几何体之间切换。
  13. 要添加更多连接，点击 Add Connection（添加连接）并从第 9 步开始重复。
  14. 为了根据网格形状变形地形，确保勾选 Terrain Deformation（地形变形）。您将在舞台上看到蓝点，它们将用作变形形状的参考。这目前适用于标准形状（如交叉口）和简单对象（如人行道），更多选项将后续添加。
  15. 点击 Apply 保存更改。

新的自定义交叉口预制体现在将出现在场景选项卡中（当选择第一个或最后一个标记时）以及预制体选项卡中，您可以在其中选择新的自定义预制体并直接在场景中实例化它。

注意：

  • 按顺时针方向添加连接，最好从底部开始。
  • 已生成的自定义预制体可以通过将预制体从资源文件夹（/Assets/EasyRoads3d/Resources/custom prefabs/）直接拖放到舞台上或 Crossing Prefab（交叉口预制体）槽中来编辑。
  • 为了以后能够编辑自定义预制体，不要从资源文件夹中删除原始网格对象。
  • 地形将根据局部 Y=0 位置平整，确保所有顶点在 Y=0 或更高位置。
  • 为避免 z-fighting（z 冲突）/闪烁，确保在分配给自定义预制体的材质上使用 EasyRoads3D 着色器之一。
  • 虽然此系统应支持相对复杂的形状，但连接应始终相对于对象中心向外；确保网格包围盒的中心在枢轴点（即图中较大的蓝点）。
  • 对于不与地形连接的预制体，系统支持非"平坦"连接（例如桥元素）。重要的是几何体连接处顶点的 UV 准确为 0 或 1，最多 0.01 的小误差可接受。如果连接不能很好地挤出，这是首先要复查的地方。
  • 由于这些预制体基于导入的网格，缩放无法自动适应不同宽度的道路类型；常规变换缩放可在 Inspector 中调整。
  • 如果在使用自己的模型时遇到问题，请通过 info@unityterraintools.com 联系我们报告，并最好附上源网格。

UV 编辑器

UV 编辑器窗口可用于对动态交叉口人行道和添加到自定义交叉口预制体的道路连接的 UV 布局进行更改。默认情况下，UV 在 0..1 范围内根据这些顶点之间的距离计算。

这些对象所用材质分配的纹理显示在画布上。在底部您将看到每个顶点的 UV 位置；如果不准确，可以将这些点移动到纹理上的匹配位置。

  • Planar UVs（平面 UV）：自动生成 UV，忽略顶点的 Y 位置。
  • Copy UVs from source mesh（从源网格复制 UV）：当从自定义交叉口编辑器窗口打开时显示。将 U 坐标设置为与匹配顶点相同的 U 值，适用于道路材质纹理与源预制体连接顶点使用的纹理完全匹配的情况。
  • Hard Edge（硬边）：当从自定义交叉口编辑器窗口打开时显示。默认情况下道路网格应继承源网格的法线组；“Hard Edge"表示所选节点匹配三角形上的平滑或硬边（只读）。

注意： 当从自定义交叉口编辑器打开 UV 编辑器窗口时，选择一个点将在自定义交叉口编辑器窗口中高亮显示相应顶点，方便确认正在调整哪个顶点的 UV。

注意： 使用"从源网格复制 UV"且连接具有封闭几何体结构（第一个和最后一个顶点位置相同）时，这些顶点通常使用 x=0 和 x=1 作为 UV 坐标。如果值被分配给了错误的顶点，在附加道路后会看到两个顶点之间显示了完整纹理。交换方法：将最左侧（0）拖到最右侧位置（1），将最右侧拖到最左侧。

自定义连接上的侧边对象

当侧边对象启用"Generate on Connections”（在连接上生成）时，当侧边对象在该连接侧的两个道路对象上都激活时，此侧边对象将在连接对象上自动生成。

曲线将在可能时自动生成，应该在边缘上。对于更复杂的自定义连接器，这可能不准确，可以在 Unity 预制体编辑器中自定义曲线。

在项目文件夹 /Assets/EasyRoads3D/Resources/custom prefabs/ 中选择生成的预制体，按 Inspector 中的"Open Prefab"按钮，确保"Side Object Data"（侧边对象数据）选项卡处于激活状态。

在这里可以为每个单独的连接设置曲线。可以在两个连接器之间的完整距离上连接侧边对象（“Join on Left side"在左侧连接、“Join on Right Side"在右侧连接），此时完整形状将可见且可编辑，系统将在两个连接器之间自动均匀分布节点。

当曲线为空或您偏好不同曲线时，可以通过输入 Node Count（节点数）创建新的节点列表。可以在视口中选择和移动节点来塑造曲线。

按相应的"Reset to Default Nodes”（重置为默认节点）按钮可将曲线重置为最初提取的节点。“Update Scene Instances”（更新场景实例）将根据新曲线数据更新场景中所有匹配对象。

LOD 组 [Pro]

LOD 组选项将根据上述设置为道路网格创建不同的 LOD 级别，这些 LOD 级别将在切换到构建模式后创建。

  • Active（激活）：激活 LOD 组系统。
  • LOD Levels（LOD 级别数）：LOD 级别数。
  • Bounds（边界）：LOD 级别切换基于道路网格相对于屏幕的边界，下一个较低 LOD 级别将在此百分比时生效。
  • Resolution（分辨率）：道路网格 LOD 级别的分辨率（百分比），最小比例为原始网格的 10%。

注意： 为了实际创建 LOD 组，构建设置中的"Build LOD Groups”（构建 LOD 组）必须激活。

注意： 为了在最低 LOD 级别后进一步剔除道路，请将该 LOD 级别的 Bounds 设置为大于 0 的值。

地形管理

EasyRoads3D 将更改场景中的 Unity 地形对象。在这里您可以创建备份和恢复原始地形。每当场景中检测到新的地形对象时，都会提示您创建备份，建议这样做。也建议在手动更改地形后更新这些备份，以保持备份最新。

备份/恢复选项也在场景中每个单独地形对象的 Inspector 中的"ER Terrain"组件中可用。

或者，您也可以通过复制项目文件夹中相应的地形资源来创建地形备份；只需将此地形资源拖放到场景中，以替换要恢复的相应地形。

Tree Distance（树木距离）和 Detail Distance（细节距离）指道路外的表面，在这些表面上应移除树木和细节对象。

附加到每个地形对象的上述"ER Terrain"组件还包含排除特定地形对象的选项，这些对象将不受道路网络影响。这对于仅在背景中使用的较低分辨率地形对象很有用；禁用这些较低分辨率地形也会导致所需的最小缩进值更小。

导入道路数据 [Pro]

外部来源的道路数据可以直接导入 EasyRoads3D v3，道路将自动创建。

默认情况下，EasyRoads3D 将数据文件中的边界与地形的边界匹配。但是，如果坐标与地形坐标不完全匹配，可以在相应的地形经度/纬度字段中输入地形边界，数据将相对于这些地形坐标进行解析。

工作流程

Open Street Map（开放街道地图）

访问 openstreetmap.org，缩放到您选择的位置。点击顶部绿色的"Export"（导出）项，您将在左侧看到经纬度坐标和附加信息；点击蓝色的"Export"按钮，这将生成一个 *.osm 文件。

对于 OSM 数据，EasyRoads3D 道路类型可以链接到 OSM 道路类型：为每个 OSM 道路类型从下拉菜单中选择对应的 EasyRoads3D 道路类型。对于 KML 文件，可以选择单个道路类型。

点击 Inspector 中的 Open OSM File（打开 OSM 文件）或 Open KML File（打开 KML 文件）按钮，选择下载的文件，系统将提取数据并创建道路。

注意： Stream OSM Data（流式 OSM 数据）选项尚未启用。
