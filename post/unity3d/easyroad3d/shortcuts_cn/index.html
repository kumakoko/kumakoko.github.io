快捷键

场景

快捷键说明
W在道路标记和交叉口对象位置手柄的三种方向模式之间切换：路径前向、路径前向水平方向、全局方向
E交叉口的旋转手柄；所选道路标记的倾斜控制
CTRL + H开关侧边对象起始/结束偏移和侧向距离的滑块手柄显示。注意起始/结束偏移手柄仅在所选标记激活时显示（选中第一个标记或前一个标记未激活时显示起始偏移手柄；选中最后一个标记或后一个标记未激活时显示结束偏移手柄）。侧向距离滑块手柄仅当侧边对象至少在一个标记上有侧向距离值且场景视图中选中相应球形手柄时显示。这些值也可在 Inspector 中设置
SHIFT + 点击在场景中实例化所选交叉口/连接
F缩放到所选道路标记；未选标记时缩放到鼠标位置。在层级中选中道路时，F 键将选择切换到道路网络对象并缩放到该道路中心，自动选择最近的标记
CTRL + Alt + 点击中间地形选项卡激活时，将点击的地形选为活动地形。切换到构建模式时仅平整此地形，有助于加快测试过程时间。再次点击同一地形将选择恢复为"All Terrains"
P将上次实例化的交叉口对象的新实例连接到所选标记（道路的第一个或最后一个标记）
O在附加到所选标记的交叉口预制体上附加下一个匹配连接
J激活/停用全局网格显示（见常规设置 > 场景设置）
K激活/停用局部网格显示（见常规设置 > 场景设置）
CTRL + K遍历可用的局部网格（见常规设置 > 场景设置）
CTRL + 空格开关场景视图道路、缩进和环绕高亮表面显示。无需在常规设置 > 场景设置中停用这些高亮表面即可快速清晰查看道路和侧边对象
SHIFT + L快捷键：常规设置 > 场景设置 > 排除已锁定对象
SHIFT + V开关地形树木和植被绘制，类似 Terrain Object > Inspector > Terrain Settings > Tree & Detail Objects > Draw。在植被茂密区域暂时隐藏树木和植被有助于更好地可视化道路

道路对象

快捷键说明
SHIFT + 点击添加标记
SHIFT + 点击标记多选标记
SHIFT + Z选择所选道路的所有标记。当前选中两个标记时，选中这两个标记之间的所有标记。场景中的变换更改或 Inspector 更改将影响所有所选标记
CTRL + 点击从所选标记（第一个或最后一个）开始新标记。适用于科幻类道路、桥梁等标记不应吸附到地面的情况
鼠标按下 + CTRL + 拖动标记仅生成侧边对象的道路网络对象在标记更改后即时更新侧边对象。涉及复杂侧边对象时使用 CTRL + 拖动，释放鼠标按钮时侧边对象才更新。注意先按鼠标按钮再按 CTRL（针对第一个和最后一个标记），否则会触发上述 CTRL + 点击事件
I插入标记
SHIFT + 点击 + 拖动移动标记位置时将标记吸附到地形高度
SHIFT + R移除所选标记或所选交叉口预制体
SHIFT + U当所选标记连接到交叉口预制体时，断开道路与连接
SHIFT + J道路类型匹配时将两条所选道路合并为一条道路。仅选中一条道路和一个标记时，SHIFT + J 将把道路分割为两条
N开关所选标记的道路形状节点选择。选中形状节点后可在场景视图和 Inspector 中更改形状。移动位置手柄时按住 Shift 将更新所选节点外侧的所有形状节点
B开关形状类型侧边对象所选标记的侧边对象节点选择。选中形状节点后可在场景视图和 Inspector 中更改形状。移动位置手柄时按住 Shift 将更新所选节点外侧的所有形状节点
M将道路标记定位到另一个路段上时按 M 键，不在两个路段之间自动生成新交叉口
SHIFT + 拖动移动标记时按住 Shift 保持标记吸附到地形。先按 Shift 时 Gizmo 中心变为平面方形，表示标记将相对于场景视图相机朝向方向移动，这在保持标记吸附到地形时通常效果更好
SHIFT + AShift + 点击添加并选中新标记后位置手柄可见，该手柄可能干扰在附近添加更多标记。SHIFT + A 将隐藏手柄
CTRL + SHIFT + M将所有标记吸附到该标记位置的地形高度
CTRL + M将所选道路标记吸附到该位置的地形高度
X按 X 键将道路 A 的标记定位到道路 B 下方或上方，避免两条道路吸附在一起。这对于桥梁情况下最大程度控制道路形状很有用。按 X 键也防止道路标记吸附在一起
拖动 Y 轴在 Y 轴上拖动道路标记位置 Gizmo 时，显示标记与地形之间的高度差
小键盘 +选择下一个标记
小键盘 -选择上一个标记

侧边对象

快捷键说明
Ctrl + 拖动与道路对象不同，仅生成侧边对象的样条对象更改形状时侧边对象会即时更新。涉及复杂侧边对象时可能导致延迟。移动标记时按 Ctrl 键仅更新样条形状，释放 Ctrl 键或鼠标按钮后侧边对象才更新
Ctrl + U在侧边对象管理器中编辑侧边对象预设时，Ctrl + U 根据当前设置更新所选道路对象上的侧边对象。这是微调侧边对象设置并查看结果的快捷方式。要求该侧边对象在所选道路上激活

侧边对象形状编辑器窗口

快捷键说明
CTRL + 点击插入节点
Del删除所选节点

注意： 必须在层级中选中道路网络对象，且场景视图窗口具有焦点，快捷键才生效。

场景操作

取消选择连接预制体

点击场景中的空白区域。所有常规道路和连接手柄将激活。

连接两条道路

按住 Shift 并点击要连接的外侧标记。当选中不同道路对象但道路对象类型相同的两个标记时，Inspector 中将显示"Join Selected Roads"按钮。
