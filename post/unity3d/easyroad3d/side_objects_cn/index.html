简介

EasyRoads3D 包含一个附加功能，可以向道路网络添加额外对象，称为侧边对象（Side Objects）。这些对象可以沿道路对象全长生成，也可以仅为特定标记段激活。

侧边对象有三种类型：

  1. 网格类型（Mesh Type）侧边对象：沿道路实例化。示例：路灯、岩石构造、道路贴花或树列。
  2. 程序化侧边对象类型：基于一个预制体，该预制体将沿道路重建并重复。示例：护栏、围墙或电线。
  3. 形状类型（Shape Type）侧边对象：生成方式与程序化侧边对象类似，但侧边对象将根据形状编辑器窗口中定义的 2D 形状生成。可以是围墙，其他示例有路肩尘带、地形细节网格覆盖层，甚至河流。这是可能的，因为侧边对象系统本身就是一个框架，它也可用于创建场景中与道路无关的其他元素。

从 v3.2 开始，特定侧边对象段（如弯道中的护栏、挡土墙、桥梁和隧道）也可以根据一组规则和该区域的地形剖面自动生成。例如，当道路到地形的高度差大于特定值（隧道阈值高度）时创建隧道；当地形与道路的高度差小于指定阈值高度时创建桥梁；当道路以大于指定弯道阈值角度转弯，或道路边缘的地形低于指定阈值高度时，创建护栏和急转标志等道具；当道路一侧的地形低于指定阈值高度，或路段重叠时，创建挡土墙。

新侧边对象的创建和现有侧边对象的编辑在侧边对象管理器中进行。v3 中的侧边对象管理器可通过 Inspector 工具栏访问，右侧第二个选项卡

注意： EasyRoads3D 还包含将标记吸附到特定对象的选项。这可以用于您自己的资源/预制体，这些对象不一定跟随道路，但与道路交互，例如桥梁预制体。详见本页底部。

提示： 当场景中选中道路对象，且侧边对象管理器中当前所选侧边对象在此道路上激活时，场景视图窗口右下角会显示刷新图标。这可用于快速可视化此侧边对象在所选道路上的更改。底部的"Update Active Scene Instances"按钮将在所有道路上更新此侧边对象。

主侧边对象设置和选项

Inspector 中的侧边对象控件根据侧边对象类型和激活的选项显示。以下涵盖所有情况，先从主侧边对象设置开始。

按钮：

  • Create New Side Object（创建新侧边对象）：添加新侧边对象。
  • Add Project Side Objects（添加项目侧边对象）：场景中的所有新侧边对象既存储在场景中，也存储在资源文件夹（/Assets/EasyRoads3D/Resources/ERSideObjectsLog）中。当资源文件夹中有尚未添加到此场景的侧边对象时，此按钮激活。按钮将打开侧边对象导入器窗口，列出所有可用侧边对象。这样可以保持场景特定侧边对象列表清晰简洁。
  • Import Side Objects（导入侧边对象）：支持从另一个项目导入侧边对象。导入侧边对象 Unity 包后（见下文导出侧边对象），点击此"Import Side Objects"按钮，将打开侧边对象导入窗口。将带侧边对象预设的预制体拖入窗口，所有侧边对象将列出，可以选择要导入哪些。
  • Manage Project Side Objects（管理项目侧边对象）：从项目中永久移除侧边对象。
  • Export Side Objects（导出侧边对象）：导出侧边对象。可以选择要导出的侧边对象。点击导出按钮后，将提示设置创建预制体的位置和名称，应在资源文件夹内。此预制体及所有依赖项将导出为 Unity 包。

侧边对象工具栏：

侧边对象可分为 7 个选项卡。其中一些选项卡还显示类别特定设置，例如桥梁选项卡同时用于桥梁和隧道。

Selected Side Object（所选侧边对象）：

显示所有控件的侧边对象。

  • Delete Side Object（删除侧边对象）：从列表中移除侧边对象，同时从所有道路对象中移除。
  • Duplicate Side Object（复制侧边对象）：创建所选侧边对象的副本，适合创建道路左侧和右侧的变体。

常规设置：

  • Side Object Name（侧边对象名称）：侧边对象的名称。
  • Side Object Type（侧边对象类型）：三种类型，Inspector 将根据所选类型更新。
  • Layer（图层）：生成的游戏对象应分配到的图层。
  • Tag（标签）：此侧边对象的标签。
  • Static（静态）：生成的游戏对象应标记为静态时勾选。
  • Scale（缩放）：程序化和形状类型侧边对象可用。
  • Cast Shadows（投射阴影）：形状和程序化侧边对象类型显示。网格类型侧边对象涉及源网格实例，其 Cast Shadows 已直接设置。
  • Default active state for each marker（每个标记的默认激活状态）：对于仅应在少数标记上激活的侧边对象，取消勾选此项。这可以节省按标记设置激活/非激活状态的时间。也可以在道路类型上和直接在道路上为此侧边对象设置。
  • Generate on Connections（在连接上生成）：当侧边对象在连接对象该侧的两个道路对象上都激活时，侧边对象将在连接对象上继续。
  • Category Tab（类别选项卡）：此侧边对象显示在哪个选项卡。
  • Auto Generate（自动生成）：侧边对象可根据规则和地形剖面自动生成。将侧边对象标记为"Auto Generate"后，当侧边对象在道路类型或单个道路上激活时，将自动生成侧边对象。两种情况下仍可停用此设置。规则按侧边对象类别而定。

护栏（Barriers）

  • Auto Generate（自动生成）：默认根据以下规则自动生成。
  • Road Bend Threshold Angle（道路弯道阈值角度）：道路弯道大于指定角度时生成此护栏侧边对象。
  • Terrain Threshold Height（地形阈值高度）：当地形与道路左侧或右侧之间的高度差大于指定高度时，此护栏侧边对象出现。
  • Start / End Offset（起始/结束偏移）：计算出的护栏侧边对象起始/结束位置将根据此值调整。

围墙（Walls）

  • Retaining Wall（挡土墙）：标记为挡墙后，侧边对象将影响地形变形。缩进位置将移到道路边缘，道路旁的地形不受影响。
  • Auto Generate（自动生成）：默认根据以下规则自动生成。
  • Terrain Threshold Height（地形阈值高度）：当地形与道路左侧或右侧之间的高度差大于指定高度时，此挡土墙侧边对象出现。
  • Start / End Offset（起始/结束偏移）：计算出的侧边对象起始/结束位置将根据此值调整。
  • Maximum Slope Angle（最大坡度角）：此挡土墙出现的最小和最大允许坡度。例如适用于阶梯墙，避免在道路角度过陡、阶梯墙预制体无法准确跟随道路的区域选中这些墙。
  • Continue Barriers and Props（继续护栏和道具）：符合地形剖面规则的自动生成护栏（如护栏）和道具默认不在挡土墙段生成。当自动生成护栏实际应在此挡土墙创建的段继续时，勾选此框。
  • Generate Other Side Objects（生成其他侧边对象）：可以将其他侧边对象链接到此侧边对象。每当此侧边对象自动生成时，链接的侧边对象将在同一段上创建，并带有相对于起始和结束的额外偏移选项。从列表选择侧边对象后将出现偏移控件。

桥梁与隧道（Bridges & Tunnels）

  • Bridge Object（桥梁对象）：桥梁类型侧边对象勾选此项。
  • Auto Generate（自动生成）：默认根据以下规则自动生成。
  • Terrain Threshold Height（地形阈值高度）：当地形与道路之间的高度差大于指定高度时，此桥梁侧边对象出现。
  • Start / End Offset Threshold Height（起始/结束偏移阈值高度）：向后/向前插值，在与地形高度差小于此值的位置开始/结束桥梁。
  • Continue Barriers（继续护栏）：符合地形剖面规则的自动生成护栏（如护栏）默认不在桥梁段生成。当自动生成护栏实际应在此桥梁创建的段继续时，勾选此框。
  • Generate Other Side Objects（生成其他侧边对象）：可以将其他侧边对象链接到此侧边对象，链接的侧边对象将在同一段上创建。
  • Tunnel Object（隧道对象）：开启后显示以下控件。

  • Bridge Object（桥梁对象）：显示之前介绍的桥梁控件。
  • Tunnel Object（隧道对象）：隧道类型侧边对象勾选此项，显示以下控件。
  • Auto Generate（自动生成）：默认根据以下规则自动生成。
  • Cut Holes（挖洞）：在 Unity 2019.3 及更新版本中，将在隧道起点和终点的地形中挖洞。此功能处于预览状态，结果高度取决于地形的 heightmapscale（地形尺寸与地形高度图分辨率之比）。目前系统针对标准 heightmapscale 优化，如高度图分辨率 513、地形尺寸 500x500 或 1000x1000。
  • Flatten Terrain Sideways（侧向平整地形）：调整道路缩进值，使地形在地形起点和终点向外平滑平整更多。值 1 表示隧道外侧部分的位置。
  • Tunnel Start Hole Offset（隧道起点洞偏移）：隧道起点与创建地形洞位置之间的最小距离。
  • Tunnel End Hole Offset（隧道终点洞偏移）：隧道终点与创建地形洞位置之间的最小距离。
  • Terrain Threshold Height（地形阈值高度）：当地形与道路之间的高度差大于指定高度时，此隧道侧边对象出现。
  • Tunnel Start Offset（隧道起点偏移）：用于微调隧道起点位置（相对于匹配地形阈值高度值的位置）。此值可自定义，可在场景视图窗口中按隧道实例微调。
  • Tunnel End Offset（隧道终点偏移）：用于微调隧道终点位置（相对于匹配地形阈值高度值的位置）。
  • Snap to Terrain（吸附到地形）：当源预制体分配了顶点颜色时显示。顶点位置将根据绿色值和到地形的距离沿道路方向向前/向后调整。绿色值为 1 时顶点完全吸附到地形。
  • Generate Other Side Objects（生成其他侧边对象）：可以将其他侧边对象链接到此侧边对象。

注意： 如上"Snap to Terrain"控件所见，可以操作单个顶点位置，使隧道与地形形状更好地融合。这通常用于代表地形、应与地形融合的隧道部分。绿色顶点颜色用于沿道路方向向前/向后移动顶点；蓝色用于向下吸附顶点，值 1 将顶点吸附到地面（用于岩石隧道示例的外侧顶点）；红色也用于将外侧顶点与地形混合，自动计算。

注意： 为使隧道良好工作，隧道预制体的起点和终点段必须足够大，以覆盖地形中的洞。这取决于地形的 heightmapscale。演示包中包含的隧道示例已在 heightmapscale 约 4（2000x2000 地形，高度图分辨率 513）的地形上测试。

如果仍有少量地形可见（如演示包中隧道起点处），有两种快速修复方法：手动绘制该洞，或使用小笔刷，用"Set Height"地形工具获取道路中心高度，并在该高度绘制可见的地形单元。

道具（Props）

道具选项卡中的侧边对象也可以自动生成，例如弯道中的急转方向标志柱。

  • Auto Generate（自动生成）：默认根据以下规则自动生成。
  • Road Bend Threshold Angle（道路弯道阈值角度）：道路弯道角度大于指定角度时生成此侧边对象。
  • Start / End Offset（起始/结束偏移）：向后/向前插值计算出的起始/结束位置，并根据此偏移值计算侧边对象的最终起始/结束位置。
  • Inactive for other side object sections（在其他侧边对象段上不激活）：开启后，此侧边对象不在已覆盖挡土墙、桥梁或隧道段的段上生成。这有助于避免此侧边对象在不需要的位置（悬浮在空中或与其他侧边对象干扰）生成。

Inspector 将继续显示侧边对象类型特定的控件。三种类型如下。

侧边对象类型：

  • 网格对象
  • 形状对象
  • 程序化网格对象

网格对象

这种侧边对象类型可用于沿轨迹实例化对象，如路灯、树木、岩石构造、独立不连接的网格围栏对象、护栏等。

  • Source Object（源对象）：将要用于此侧边对象的游戏对象/预制体拖入此槽。
    • Prefab Childs（预制体子对象）：当预制体中有超过 1 个子对象时启用。正确使用方式是将所有单个对象设置为父预制体的子对象。有 3 个选项：
      • All（全部）：每个新实例实例化所有子对象。
      • Child Sequence（子对象序列）：按子对象索引遍历所有子对象，每个实例实例化一个子对象。
      • Random Mesh（随机网格）：每个实例随机选择一个子对象。如果希望特定对象更频繁地实例化，只需在预制体中复制它们，增加被选中的机会。
    • Terrain Vegetation（地形植被）：下拉框显示当前添加到地形对象的所有树原型。选择其中一个原型将把关联的预制体移到源对象槽。切换到构建模式时，所有实例化的树将添加到地形植被数据中，具有树木公告板等所有优势。
  • Minimum Scale（最小缩放）：每个实例的最小缩放。值 1 表示源预制体的原始缩放。
  • Maximum Scale（最大缩放）：每个实例的最大缩放。

控制设置：

  • Position（位置）：根据下拉菜单中所选选项侧向移动对象。选项：

    1. 相对于道路中心
    2. 相对于道路左侧
    3. 相对于道路右侧

    当位置相对于道路左侧或右侧时，侧边对象可标记为"Dual Sided"（双面），表示该对象可用于道路两侧。道路另一侧的对象对齐方式可在下拉菜单中选择旋转"Rotate 180 Degrees"或镜像"Mirror"。当 Synch Left Right（左右同步）激活时，左右两侧将对齐，包括在弯道中。这例如适用于路灯。

  • Distance between objects（对象间距）：实例化对象之间的距离。

    • Random Distance（随机距离）：在 0 到输入值之间添加随机距离。
    • Average by Road Length（按道路长度平均）：默认开启。“对象间距"将重新计算，使最后一个实例位于轨迹末端。关闭后使用精确的"对象间距"值。

  • X Position（X 位置）：相对于默认位置侧向移动对象。

  • Random X Position（随机 X 位置）：向 X 位置值添加额外随机偏移。

  • Y Position（Y 位置）：向上移动对象。

  • Y-axis Rotation（Y 轴旋转）：控制 Y 轴旋转。选项：“Follow Road”（跟随道路）、“Fixed”（固定）和"Random”（随机）。

    • Add Rotation Angle（添加旋转角）：将输入值添加到计算的旋转值，可用于微调例如弯道中侧边对象的旋转。

  • Mesh Bounds Alignment（网格包围盒对齐）：默认情况下对象根据该点的前向方向旋转。这对于 X 和 Z 轴包围盒较小的侧边对象（路灯等）效果好，但对于 X 和 Z 轴包围盒较大的对象（例如单个围栏对象）不够准确。开启此选项将根据对象大小精确对齐实例化对象。

  • End Connection Object（结束连接对象）：网格包围盒对齐激活时生效。例如在围栏预制体形成的围栏末端添加柱子。

  • Default Start Offset（默认起始偏移）：选择第一个标记后可在道路上直接为每段设置起始偏移。此处可设置默认起始偏移。

  • Default End Offset（默认结束偏移）：选择倒数第二个标记后可在道路上直接为每段设置结束偏移。此处可设置默认结束偏移。

  • Snap to Terrain（吸附到地形）：默认侧边对象的 Y 位置与该位置的道路对齐。这对道路附近的侧边对象有效，在桥段激活时也能正确构建。对于围栏等侧边对象，特别是使用上述按标记的侧向距离选项将对象移向/移离道路时，通常希望将侧边对象吸附到地形，这就是此选项的作用。对于非道路相关对象，该对象设置中"Snap to Terrain"的状态优先。

  • Alignment（对齐）：可将侧边对象与地面对齐，选项：

    • None（无）
    • Terrain Normal（地形法线）
    • Path Forward（路径前向）
    • Path Normal（路径法线）

    注意： 使用侧向距离选项（按标记）时，将创建新的样条形状，这意味着与道路形状的连接丢失，因此 Path Forward 和 Path Normal 选项不再准确。但 Terrain Normal 选项几乎相同，仅在地形未按道路形状平整的区域外有不同结果。

    选择"None"且开启"Mesh Bounds Alignment"时，第二个下拉菜单将根据此实例覆盖的地形高度控制对齐，例如将特定类型的围栏和墙与地面对齐：

    • Lowest Point（最低点）：实例 Y 位置匹配最低地形点。
    • Highest Point（最高点）：实例 Y 位置匹配最高地形点。
    • Average height（平均高度）：实例 Y 位置匹配平均高度。

  • Random Rotation Angle（随机旋转角）：在 X 轴上旋转对象。

  • Combine Objects（合并对象）：根据所用材质，将所有实例化对象合并为单个对象。

  • Update Active Scene Instances（更新活动场景实例）：此按钮位于 Inspector 底部，更改后启用。点击此按钮自动更新所选侧边对象的所有场景实例。

桥梁对象

[已废弃]： 与其将静态桥梁网格用作侧边对象，在 v3.2 中建议将 MarkerSnap 控制器添加到这些静态预制体。道路标记可以快速附加到这些 MarkerSnap 控制器，使道路与桥梁完美对齐。

这适用于不应适应道路形状的桥梁，如标准高速公路桥梁。这种侧边对象类型基于固定桥梁模型。选择网格对象类型并开启 Bridge Object 时，显示桥梁特定控件：

  • Source Object（源对象）：将要用于此侧边对象的桥梁游戏对象/预制体拖入相应槽。
    • Prefab Childs（预制体子对象）：可选。可用于随机选择桥梁预制体。注意基础结构（高度和长度）应相似以获得准确结果。

控制设置：

  • X Position（X 位置）：微调最终位置。
  • Y Position（Y 位置）：微调最终位置。
  • Bridge Height（桥梁高度）：上方道路标记与下方道路标记之间的高度差。
  • Marker Spline Control（标记样条控制）：此侧边对象将开启的标记的控制器类型。一般使用 Straight XYZ。为标记激活桥梁侧边对象时，相应的控制器类型将自动更新。
  • Deformation Level Distance（变形平整距离）：地形从道路高度平整到原始地形高度的距离。这将自动更新所选标记相应的 Start Level Distance 和 End Level Distance。
  • Marker Indent Distance（标记缩进距离）：根据此值自动更新所选标记和下一个标记的缩进值。这是为桥梁附近地形变形添加变化的快捷方式。
  • Marker Surrounding Distance（标记环绕距离）：根据此值自动更新所选标记和下一个标记的环绕值。这是为桥梁附近地形变形添加变化的快捷方式。

每个控件右侧的按钮在选中带有此侧边对象激活的道路标记时激活。此外可以选择下一个标记以及从桥下穿过的道路的相应标记。所有这些按钮选中时，所有按钮都将激活，值将根据场景中当前标记设置自动计算。

建议设置方式：在平坦地形上创建两条交叉的道路。为上方道路激活侧边对象，将下一个标记定位到"Bridge End"（桥梁末端）位置，选中两个标记并将它们升高到相对于下方道路的正确高度。也选择下方两个标记，侧边对象管理器中的所有按钮都激活，现在可以点击按钮设置值。

要激活 Get Length 按钮，也可以暂时将子对象添加到源预制体上的精确标记位置，将这些子对象命名为"marker1"和"marker2"。Get Length 按钮将激活。这是设置桥梁长度值的更精确方式，之后可以从预制体中移除这些临时子对象。

在场景中激活此桥梁并选择相同的 4 个标记时，您将在 Inspector 中看到所有必需的对齐按钮（工具栏正下方），可快速准确地对齐道路，使桥梁完美贴合。

形状对象

这种侧边对象将根据 2D 形状编辑器窗口中定义的 2D 形状沿轨迹程序化创建形状。可用于创建例如挡土墙或河流侧边对象，包括河床形状（相应地变形地形）和河流水面网格本身。

  • Target Object（目标对象）：可选地选择目标预制体。此预制体将被实例化，程序化创建的形状将添加到此预制体的网格资源。如果要创建附加脚本的形状，这很有用。例如可以将 Unity 水预制体之一拖到此槽，定义模拟水面的简单水平形状。最终对象将自动附加所有水脚本和材质。
  • Material（材质）：此侧边对象应使用的材质。上方已分配设置好材质的目标对象时不需要。
  • Start Object（起始对象）：可用于将起始游戏对象附加到形状。在 v3 中，建议对同时包含起始/结束对象的侧边对象使用程序化网格对象。
  • Connection Object（连接对象）：此对象将在每个新段实例化。
  • End Object（结束对象）：可用于将结束游戏对象附加到形状。在 v3 中，建议对同时包含起始/结束对象的侧边对象使用程序化网格对象。
  • Open Shape Editor Window（打开形状编辑器窗口）：打开编辑器窗口定义侧边对象的形状。

控制设置：

  • Clamp to Road Geometry（贴合道路几何）：每段将匹配道路几何分辨率构建。当侧边对象应精确跟随道路形状（包括弯道）时很有用，例如赛道上的路缘。
  • Geometry Resolution（几何分辨率）：顶点行之间的距离，控制几何分辨率。
  • Position（位置）：根据下拉菜单中所选选项侧向移动对象（相对于道路中心/左侧/右侧）。相对于左侧或右侧时可标记为"Dual Sided"，另一侧可选择旋转 180 度或镜像。
  • X Position（X 位置）：相对于上述所选默认位置侧向移动对象。
  • Y Position（Y 位置）：向上移动对象。
  • Default Start Offset（默认起始偏移）：默认起始偏移。
  • Default End Offset（默认结束偏移）：默认结束偏移。
  • Snap to Terrain（吸附到地形）：将侧边对象吸附到地形。
  • Alignment（对齐）：（未激活）对齐选项同网格对象。
  • UV Tiling（UV 平铺）：沿形状的 UV 分布。
  • Flip UVs（翻转 UV）：侧向翻转 UV。
  • Clamp V（钳制 V）：UV 将沿轨迹分布，使其终止于整数倍。可选地在 0..1 范围以小数定义目标值。
  • Combine Section（合并段）：根据所用材质，将所有实例化对象合并为单个对象。
  • Add Mesh Collider（添加网格碰撞体）：激活后自动为生成的网格添加网格碰撞体。
  • Update Active Scene Instances（更新活动场景实例）：自动更新所选侧边对象的所有场景实例。

程序化网格对象

如侧边对象简介所述，这种侧边对象类型将基于在 Unity 外部创建的预制体（源对象）程序化创建网格。

这种侧边对象类型可用于创建围栏、围墙、护栏等侧边对象，也可用于复杂桥梁。

源对象模型可以包含起始、中间和结束段。只有中间段会重复。起始、中间和结束段可在网格编辑器窗口中定义。

  • Source Object（源对象）：将源网格游戏对象/预制体拖到此槽。使用[命名规范]设置源对象时显示附加信息，侧边对象特定数据将自动提取。

  • Start Object（起始对象）：附加起始游戏对象。

  • Connection Object（连接对象）：在每个新段实例化。

  • End Object（结束对象）：附加结束游戏对象。

  • Open Mesh Editor Window（打开网格编辑器窗口）：打开为侧边对象系统准备源网格的编辑器窗口。

控制设置：

  • Clamp to Road Geometry（贴合道路几何）：每段匹配道路几何分辨率构建。为此要良好工作，源对象大小应与道路分辨率相似。
  • Position（位置）：侧向位置选项同前（中心/左/右、Dual Sided）。
  • X Position（X 位置）：侧向移动对象。
  • Random X Position（随机 X 位置）：向 X 位置添加随机偏移。
    • Min / Max Distance（最小/最大距离）：随机位置变化发生的距离。
  • Y Position（Y 位置）：向上移动对象。
  • Random Y Position（随机 Y 位置）：向 Y 位置添加随机偏移。
    • Min / Max Distance（最小/最大距离）：随机位置变化发生的距离。
  • Default Start Offset（默认起始偏移）：默认起始偏移。
  • Default End Offset（默认结束偏移）：默认结束偏移。
  • Snap to Terrain（吸附到地形）：吸附到地形。
  • Alignment（对齐）：对齐选项同前。
  • Random Rotation Angle（随机旋转角）：在 X 轴旋转对象。
    • Min / Max Distance（最小/最大距离）：随机旋转变化发生的距离。
  • Combine Section（合并段）：合并为单个对象。
  • Add Mesh Collider（添加网格碰撞体）：添加 MeshCollider 组件。
  • Add Box Collider（添加盒碰撞体）：添加匹配每段包围盒的盒碰撞体。
    • Collider Scale（碰撞体缩放）：盒碰撞体可设置盒子缩放。
  • Update Active Scene Instances（更新活动场景实例）：更新所有场景实例。

提示： 使用 H 键切换场景视图中侧边对象手柄的显示。

形状编辑器窗口

形状编辑器窗口用于在 2D 空间中为[形状类型]侧边对象定义形状，点击 Inspector 底部常规设置中显示的 Open Shape Editor Window 按钮后打开。

在舞台上双击添加点（或 Ctrl + 双击插入点）。添加第二个点后，点将连接。

  • Trace Object（追踪对象）：可选地使用模型提取形状，可追踪顶点的焦点在 z = 0。
  • Trace on（追踪轴）：根据模型导入 Unity 的方式，可能需要更改方向。
  • Selected Index（所选索引）：所选点的索引。选中节点时以下选项可用：
    • X / Y：所选点的 X 和 Y 值，可编辑精确值。
    • Terrain Snap Weight（地形吸附权重）：在原始位置和地形高度之间对相应顶点进行插值。值 1 将顶点吸附到地形。
    • Vertex Color（顶点颜色）：生成的网格将包含顶点颜色信息，可在附加的着色器中使用。可选地为每个形状点设置顶点颜色。
    • Hard Edge（硬边）：在所选顶点创建硬边。
  • Close Geometry（闭合几何体）：将最后一个点连接到第一个点。
  • Create Start / End Caps（创建起始/结束封盖）：在生成网格的起点和终点闭合网格。起始和结束形状都将在可通过下方"UV Editor"按钮打开的 UV 编辑器窗口中可见。
  • Clamp UVs（钳制 UV）：将 UV 钳制在 0..1 之间，包括顶点吸附到地形时。
  • Clamp UV4（钳制 UV4）：在 uv4 中添加额外 UV 坐标，并在顶点吸附到地形时保持相同的 UV 分布。这对于自定义着色器和钳制到地形导致不规则形状的网格很有用。
  • UVs Relative to Terrain（UV 相对于地形）：主 UV 集将相对于地形边界创建。
  • Blend Terrain in UVs（UV 中混合地形）：地形表面覆盖层激活时生效。UV 计算将考虑顶点颜色（alpha 通道）。
  • Preserve Node Direction（保持节点方向）：顶点具有地形吸附权重值时激活。新顶点位置将沿原始方向计算，而不是垂直向下。

按钮：

  • Mirror Horizontally（水平镜像）：在 Y 轴上镜像点。
  • Mirror Vertically（垂直镜像）：在 X 轴上镜像点。
  • Flip Faces（翻转面）：发现法线指向相反方向时点击此按钮。
  • UV Editor：打开 [UV 编辑器窗口] 微调或自定义 UV。必须先为此侧边对象分配材质，否则此选项禁用。
  • Apply（应用）：保存更改并更新所有现有场景实例。

舞台可以通过按住左键移动鼠标拖动。使用滚轮或 Shift+点击+拖动缩放；按住 Shift 选择和移动多个点。

快捷键：

  • R 键：舞台居中。
  • Z 键：缩放舞台使输入点的包围盒完全可见。
  • 滚轮：放大/缩小。
  • Ctrl + 双击：插入节点。
  • Del 键：删除所选节点。
  • Shift + 选择节点：多选节点。

UV 编辑器

形状类型侧边对象的 UV 根据节点间距离和上述形状编辑器窗口中的 UV 设置自动计算。侧边对象材质的主纹理将显示为参考。

节点位置以黑色竖线表示。底部黑点可选中（变绿）并水平拖动以微调 UV。

当形状侧边对象设置为包含起始/结束封盖（在形状编辑器窗口中）时，这些形状也将可视化，包括定位、缩放、旋转形状的控件，使 UV 匹配纹理。

  • No Node Selected（未选节点）：选中节点时可手动输入 U 位置。
  • Hard Edge Padding（硬边填充）：可选地在硬边添加填充。值相对于 0..1。
  • Reset UVs（重置 UV）：按距离重新计算 UV。
  • Reset UVs Relative to Most Right（相对于最右侧重置 UV）：同上但相对于最右侧节点。这样可以在纹理右侧保留空间，特别是起始/结束封盖。

创建起始/结束封盖时显示以下控件，起始封盖和结束封盖各一组：

  • Scale（缩放）：封盖形状将可视化，可缩放。
  • X Pos（X 位置）：水平移动形状的滑块。
  • Y Pos（Y 位置）：垂直移动形状。
  • Rotation（旋转）：旋转形状。
  • Color（颜色）：形状轮廓颜色。

网格编辑器窗口

网格编辑器窗口用于为[程序化网格对象]类型侧边对象准备几何结构，点击 Inspector 中的 Open Mesh Editor Window 按钮后打开。

完整网格结构可用于每段，也可以将网格拆分为起始和/或结束段及中间段。

  • Source Object（源对象）：用作此侧边对象基础的网格。
  • Trace on（追踪轴）：根据模型导入 Unity 的方式可能需要旋转对象。

    提示： 目前最佳处理方式是将游戏对象拖到场景中查看 Inspector。Unity 是否自动应用了旋转值？在这种情况下建议创建新预制体，将模型作为此预制体的子对象，并在预制体中对此子对象应用相同的旋转值。将新预制体分配为源对象。查看演示项目，所用资源为 .obj 文件。Unity 在 Y 轴上应用 180 度旋转。这就是为什么使用预制体，原始网格作为子对象，子对象在 Y 轴上有 180 度旋转。

  • Mirror Horizontally（水平镜像）：例如快速创建护栏等侧边对象的左/右版本。在 Inspector 中复制侧边对象，打开编辑器窗口，勾选"Mirror Horizontally"并点击 Apply 按钮。
  • Include Start Segment（包含起始段）：添加起始段。
  • Start Segment Offset（起始段偏移）：定义几何在起始段和中间段之间的拆分位置。最佳方式是在舞台上，将蓝色底部手柄之一拖到起始段和中间段之间的边缘，手柄将在吸附范围内吸附到顶点。
  • Smooth Normals（平滑法线）：激活后在段之间生成平滑法线。
  • Incl. Start Edge Triangles（包含起始边缘三角形）：有时希望起始边缘上的三角形属于中间段，勾选此框实现。
  • Incl. End Edge Triangles（包含结束边缘三角形）：有时希望结束边缘上的三角形属于中间段，勾选此框实现。
  • Include End Segment（包含结束段）：添加结束段。
  • End Segment Offset（结束段偏移）：定义几何在中间段和结束段之间的拆分位置。在舞台上将蓝色顶部手柄之一拖到结束段和中间段之间的边缘。
  • Smooth Normals（平滑法线）：在段之间生成平滑法线。
  • Adjust To Road Width（调整到道路宽度）：桥梁等侧边对象在激活 Active 复选框后将调整到道路宽度。
  • Offset（偏移）：偏移值定义此侧边对象上道路左右边缘的位置。设置偏移的最佳方式是水平拖动激活此选项后在舞台上可见的蓝色手柄。
  • Build Test Meshes（构建测试网格）：在场景中生成起始/中间/结束段的测试对象，用于检查段是否正确生成。这些段位于主道路网络游戏对象下新的临时游戏对象"tmp folder"中，点击 Apply 或 Close 按钮后自动删除。
  • Apply（应用）：保存更改并自动更新场景中所有现有实例。
  • Close（关闭）：关闭编辑器窗口。

起始段偏移技巧： 为获得最佳结果，边缘上的顶点需要在同一 Z 位置。如果未得到预期结果，可以从另一侧进行吸附验证——是否确实产生不同的几何？如果是，建议在建模应用程序中复查顶点位置。对于起始段，建议（根据几何复杂度）将手柄拖到吸附点上方，然后向下移动直到吸附到所需边缘。对于结束段，建议将手柄拖到吸附点下方，然后向上移动直到吸附到所需边缘。

提示： 从简单对象开始熟悉系统并尝试所有不同设置。程序化网格对象也从简单网格开始熟悉系统，查看演示项目中网格的设置，了解在网格编辑器窗口中如何定义起始/结束偏移。

程序化侧边对象命名规范

从 v3.2 开始，程序化侧边对象也可以使用命名规范设置。当源对象使用命名规范时，将显示详细信息摘要。

目前支持起始、结束和中间段。将代表这三个段的每个对象名称分别以 _start、_middle 或 _end 结尾，将自动拆分对象并相应生成侧边对象：以 _start 对象开始，后跟重复的 _middle 段，以 _end 对象结束。

上图是演示包中"Concrete Tunnel"示例的源预制体，包含隧道段的起始、中间和结束段，以及地形细节段的起始和结束段。源对象将自动提取两段的所有 3 个段。

除了可以在建模应用程序中设置段外，这种方法的另一个优点是起始和结束段可以与中间段重叠，这为更复杂的网格提供了额外控制。

默认情况下程序化侧边对象投射阴影。可以在常规设置中关闭，名称中包含 _castShadowsOff 的源预制体也将关闭。

还支持 _stepDown 和 _stepUp 命名规范。系统将检测主子对象与这些阶梯版本之间的高度差，该高度差将显示在摘要中。使用阶梯设置时，侧边对象段将以固定高度生成。一旦样条高度与当前段高度之间的差超过此阶梯高度差，将插入相应的阶梯子对象，新的侧边对象段将从这个新高度开始。演示包中的"Stepped Wall"侧边对象就是示例。

_terrain 命名规范可用于应沿前向吸附到地形的隧道段。演示包中混凝土隧道和岩石隧道示例的岩石部分使用了此命名。系统将分配顶点颜色，绿色通道用于此。顶点越靠外，绿色值越强，地形吸附权重越强。为精确起见，此信息也可以直接在源预制体的顶点颜色数据中提供。

在 v3.2.x 中还可以为不同 LOD 级别添加子对象，将自动创建 LOD 组。

跨场景侧边对象工作流

项目中使用的所有侧边对象存储在资源文件夹中。场景中使用的所有侧边对象存储在场景数据中。

创建新场景并添加道路网络对象后，系统将检查项目中是否有可用侧边对象，如果有，将询问是否要将这些侧边对象添加到新创建的道路网络对象。选择否时，仍可以导入所有这些侧边对象或项目侧边对象的一部分。手动导入所选项目侧边对象有助于保持侧边对象列表清晰简洁。

对侧边对象进行更改后，项目文件夹中的关联侧边对象也将更新。在场景中选择道路网络时，系统将检查侧边对象更改并更新场景侧边对象数据。此时场景本身不会更新，可以手动更新。在下次更新中，这种情况下将询问是否要更新场景。

场景中侧边对象工作流

向场景中的道路添加侧边对象有两种方式。

可以在场景中为道路激活侧边对象，这在所选道路的[侧边对象部分]的 Inspector 中完成。

第二种方式是在常规设置 > 道路类型中为[道路类型]自动激活侧边对象。这些侧边对象将为此道路类型的新实例自动激活。仍可以通过选择道路（点击蓝色标记手柄之一）并在所选道路的[侧边对象部分]中取消勾选特定侧边对象，来为特定道路停用任何这些侧边对象。

为道路激活侧边对象后，将使用侧边对象管理器中设置的默认设置（上文已介绍）。可以微调一部分控件。激活侧边对象时将出现折叠箭头，可打开并[显示所有选项]。

选择标记后，激活的侧边对象可以通过多种方式为该标记段微调。选择标记并从下拉菜单中选择要更改的侧边对象，将有若干标记特定选项[可用]。

自动生成的侧边对象将根据规则集和地形剖面自动创建。有时可能希望忽略某些自动生成的段，或在此道路上有多个相似侧边对象激活时更改所选侧边对象。这可以通过点击生成的对象完成，场景视图窗口左上角将显示实例特定控件。

右上角的关闭图标可用于关闭窗口。这在意外点击自动生成的侧边对象时很有用。在场景其他位置点击也会关闭窗口，但在某些情况下（例如多选标记时）应避免，因为点击场景时多选标记也会丢失。

将显示道路名称以及侧边对象段的名称和状态：

  • Active（激活）：可以关闭。侧边对象仍可见（透明）以便仍可选中，但在构建模式下此段将被忽略。
  • Side Object（侧边对象）：此段存在多个侧边对象时，可从下拉菜单选择另一个。
  • Keep Selected（保持所选）：系统将根据地形剖面和每个侧边对象设置的规则选择最佳匹配。仍可以在上方选择其他可用侧边对象。此"Keep Selected"选项可用于强制在此区域道路更改后使用当前所选侧边对象。

注意： 对于标记为自动生成的侧边对象，仍支持按标记激活此侧边对象。

注意： 自动生成的侧边对象将继承此侧边对象类型可能已调整的标记 X 位置值。

注意： “跟随地形轮廓"选项会干扰桥梁和隧道等自动生成的侧边对象。关闭相关标记的"跟随地形轮廓"将在这些段生成桥梁和隧道。

标记吸附连接器

标记吸附对象可用作场景中道路标记的连接点。将道路标记向这些对象移动时，在吸附范围内将吸附到此对象。这是将道路与其他对象（如非侧边对象系统生成的桥梁对象）对齐的快捷方式。

通过将这些标记吸附连接器添加到项目文件夹中桥梁预制体的战略位置，新场景实例在拖入场景后即可准备就绪并设置完毕。

标记吸附连接器预制体位于 /Assets/EasyRoads3D/Prefab Sources/Additional Prefabs/ERMarkerSnapConnector/。

可以选择和复制此预制体，然后将副本添加到特定预制体。单个预制体可添加多个标记吸附连接器。

例如桥梁可以有四个标记吸附连接器，演示场景中的 Motorway_2L_bridge_prefab 就是示例。

可选地，附加到特定标记吸附连接器后可自动设置标记特定控件。

  • Terrain Deformation Control（地形变形控制）：吸附到此对象的标记将关闭地形变形。这可用于桥梁预制体上不应调整地形的道路。
  • Marker Indent（标记缩进）：左右标记缩进值（地形在与道路相同高度平整的距离，道路边缘与地形边缘）将自动调整。这在适当情况下提供对地形变形的更多控制。
  • Marker Surrounding（标记环绕）：左右标记环绕值（地形从新高度逐渐平整到原始地形高度的距离）将自动调整。这在适当情况下提供对地形变形的更多控制。
