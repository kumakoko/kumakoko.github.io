简介

场景选项卡 将显示当前道路网络的信息。您可以选择用于移动标记的手柄，选择道路或交叉口对象后，Inspector 将显示该对象的信息。

道路属性

在[添加道路]或选择现有道路的标记（蓝色球形手柄）后，将显示道路属性：

道路名称右侧的小锁图标可用于锁定道路并禁用所有控件。

道路名称下方是道路统计信息：总长度/距离（米或公里，基于 1 个 Unity 单位 = 1 米）、总顶点数和三角形数。

控件分为 6 个可折叠子菜单。每个子菜单可单独打开；按住 Shift 键选择子菜单时，将关闭所有其他打开的子菜单。

道路名称右侧的锁图标可锁定所有道路设置，锁定状态下道路无法编辑。结合场景设置中的"排除已锁定对象"选项，这也可用于在场景视图中隐藏道路手柄。

问号按钮将打开相关的在线文档。

道路设置

可以显示所有道路设置控件（下图 UI），也可以将道路设置 UI 最小化为最常用控件（上图 UI）。点击底部的"Show More +“将显示所有控件。

主要设置：

  • Road Name（道路名称）：道路的名称。
  • Road Type（道路类型）：所选道路类型。只要道路未连接到交叉口，就可以更改为任何其他道路类型；否则只能更改为形状设置相似、节点数量也与交叉口连接形状匹配的道路类型。
  • Closed Track（闭合轨迹）：将道路循环闭合，非常适合生成赛道。
  • Road Width（道路宽度）：道路宽度。分配了道路类型时此字段不显示，此时可在"常规设置 > 道路类型"中更改道路宽度，这样基于该道路类型的所有道路实例和交叉口连接的宽度都可以即时更新。

细节设置：

  • Sub Segments（子分段）[Pro]：可用于细分道路网格以获得更多细节。注意动态交叉口尚不支持此功能。分配道路类型时此字段不会被禁用。
  • Resolution（分辨率）：以米为单位的几何分辨率。
  • Angle Threshold（角度阈值）[Pro]：可用于优化道路几何形状，同时保持弯道细节。尝试约 5 的值，并将道路分辨率提高到 10 或 20，顶点/三角形数量将显著下降。一般不建议使用低于 4 或 5 的角度阈值，除非追求高清晰度。
  • Road Smoothness（道路平滑度）[Pro]：
    • Bumpiness Y Offset（起伏 Y 偏移）：道路的平滑度，可通过最小/最大值控制。
    • Bumpiness Distance（起伏距离）：距离，可通过最小/最大值控制。
    • Random Tilting Angles（随机倾斜角）：为道路添加额外倾斜，可通过最小/最大值控制。
    • Tilting Distance（倾斜距离）：倾斜发生的距离。
  • Follow terrain Contours（跟随地形轮廓）[Pro]：道路将自动调整以适应地形形状，这将大大加快工作流程，因为需要的标记更少。
  • Contour Threshold（轮廓阈值）[Pro]：值越低，道路越贴合地形形状；高速公路等道路使用更高值。这是一个 DelayedFloatField，更改值后按 Enter 更新道路。

材质与贴花设置：

  • Road Material（道路材质，未选道路类型时）：分配给此道路的材质。下拉菜单列出 /EasyRoads3D/Resources/Materials/Roads 中的所有材质。但建议使用道路类型，并将材质更改应用到道路类型。
  • Physics Material（物理材质，未选道路类型时）：可选地分配物理材质。
  • UV Tiling（UV 平铺）：控制所用道路纹理的平铺大小。
  • Additional UV data（额外 UV 数据）：可在 UV 通道 4 中生成与地形包围盒匹配的额外 UV 数据，或按指定距离平铺的 UV 数据。
  • Flip Road Texture / UVs（翻转道路纹理/UV）：交换道路的 UV 坐标。默认情况下，连接上对向道路的纹理无论如何连接到交叉口都会匹配；如果特定道路不希望这样，可以翻转该道路的道路纹理。当连接到自定义连接器的道路 UV 看起来错误或翻转时，此选项也很有用。
  • Flip Normals（翻转法线）：对于通过自定义预制体系统生成的轨迹可能很有用。有时希望法线指向另一个方向，例如隧道/洞穴类形状。
  • Start Decal（起点贴花）：当前起点处选中的贴花，可从下拉菜单手动选择其他贴花进行更新。贴花可用作交叉口处道路类型之间的过渡，或添加变化、裂缝、道路修补。贴花预制体可按道路类型在"常规设置 > 道路类型"中添加。
  • End Decal（终点贴花）：当前终点处选中的贴花，可从下拉菜单手动选择其他贴花进行更新。用途同起点贴花。

对象设置：

  • Terrain Deformation（地形变形）：可用于关闭此特定道路的地形变形，例如用作桥段的道路。
  • Layer（图层）：此对象所在的图层。
  • Tag（标签）：此对象的标签。
  • Cast Shadows（投射阴影）：对象应投射阴影时开启。

按钮：

  • Delete Object（删除对象）：移除对象。
  • Select Object in Hierarchy（在层级中选择对象）：选择实际的道路对象，提供在层级中快速选中该道路的方式。
  • Duplicate Object（复制对象）：复制对象，适合需要一系列相似形状对象时使用。
  • Export Object（导出对象）：将所选道路导出为 .obj。

    注意： 在较新的 Unity 版本中可以导出为 FBX。从 Package Manager 导入额外的 FBX Exporter 包，它会在 GameObject > Export To FBX 中添加 FBX 导出选项。在 FBX 导出设置中取消勾选"Export Unrendered”。

  • Show More + / Show less -（显示更多/更少）：将主要道路控件的显示最小化/最大化，仅显示最常用控件或所有可用控件。

侧边对象

场景中所有可用的侧边对象将列在此处，与侧边对象管理器中的列表方式类似。您可以选择为此道路对象激活哪些侧边对象。

折叠菜单将显示额外控件，用于调整此侧边对象特定实例的[默认设置]。此外，“Auto Generate”（自动生成）选项（适用于护栏、挡土墙、桥梁、隧道）可用时可以禁用；在该状态下，侧边对象可以按标记激活。

另有 5 个按钮：

  • Refresh Side Object（刷新侧边对象）：侧边对象随机生成时此选项很有用。
  • Reset（重置）：将侧边对象重置回侧边对象管理器中的默认值。
  • Export Side Object（导出侧边对象）：将侧边对象导出为 .obj 格式。
  • Select Side Object in Hierarchy（在层级中选择侧边对象）：在层级中选择该侧边对象。
  • Select in Side Object Manager（在侧边对象管理器中选择）：打开侧边对象管理器并选中该侧边对象。

标记属性

可以显示所有道路标记设置控件（下图 UI），也可以将标记设置 UI 最小化为最常用标记控件（上图 UI）。点击底部的"Show More +“将显示所有控件。

顶部显示所选标记编号，其后是标记段距离、平均角度和平均坡度。

主要设置：

  • Position（位置）：所选标记的 XYZ 位置。
  • Tilting（倾斜）[Pro]：所选标记的倾斜角（可使用 E 键直接在场景视图中控制）。对于有地形变形的对象，旋转角度锁定为最大 30 度；其他对象可完整旋转 360 度，这对于 FX 类轨迹很有用。
  • Tilting Center（倾斜中心）[Pro]：旋转的原点。
  • Control Type（控制类型）[Pro]：每个标记可选择控制类型。
    • Spline Controller（样条控制器）：默认控制器，创建平滑曲线。
    • Straight XZ（直线 XZ）：以直线连接此标记与下一个标记，但高度平滑过渡。
    • Straight XYZ（直线 XYZ）：以完美直线连接此标记与下一个标记。
    • Circular（圆形）：根据与前一个标记的角度，在所选标记与下一个标记之间创建圆形形状。
  • Curve Strength（曲线强度）：使用样条控制器作为控制类型时可用，控制样条形状的强度。
  • Segment Smoothness（分段平滑度）：
    • Bumpiness Y Offset（起伏 Y 偏移）：此标记段的平滑度，可通过最小/最大值控制。
    • Bumpiness Distance（起伏距离）：此标记段的起伏距离，可通过最小/最大值控制。
    • Random Tilting Angles（随机倾斜角）：为标记段添加额外倾斜，可通过最小/最大值控制。
    • Tilting Distance（倾斜距离）：倾斜发生的距离。

地形控制：

  • Left Indent（左缩进）：道路左侧地形应平整到相同高度的距离。
  • Left Indent Alignment（左缩进对齐）：可用于在丘陵地区操纵地形变形。
    • Align with Road（与道路对齐）：默认选项，一般使用此设置。
    • Align with the terrain（与地形对齐）：将缩进值捕捉到该点的地形高度。
    • Align with surrounding position（与环绕位置对齐）：将缩进位置设置为与相应左侧环绕位置相同的高度。
    • 后两个选项在丘陵地区很有用，可通过侧边对象系统（特别是 Shape Object 类型）用网格模拟地形，为道路附近的地形增加更多细节。
  • Left Surrounding（左环绕）：地形逐渐平整到原始地形高度的距离。
  • Right Indent（右缩进）：道路右侧地形应平整到相同高度的距离。
  • Right Indent Alignment（右缩进对齐）：与左缩进对齐相同，但作用于道路右侧。
  • Right Surrounding（右环绕）：地形逐渐平整到原始地形高度的距离。

    注意： 以上缩进、环绕和对齐控件在"常规设置 > 场景设置"中的高亮表面（可视化缩进和环绕区域的表面）激活时可见。

  • Follow Terrain Contours（跟随地形轮廓）[Pro]：当主要道路设置中的"跟随地形轮廓"勾选时此选项启用。可用于关闭特定单个标记的此功能，例如在丘陵地区创建凸起弯道，或确保自动生成的侧边对象（如隧道或桥梁）在特定区域生成。
  • No Terrain Deformation（无地形变形）：停用此标记段的地形变形，例如桥段需要。
  • Start Level Distance（起始平整距离）：在桥段起点，地形高度从道路高度平整到原始地形高度的距离。
  • End Level Distance（结束平整距离）：在桥段终点，地形高度从道路高度平整到原始地形高度的距离。
  • Fade In Distance（淡入距离）[Pro]：选择第一个标记时显示。可用于在 x 米距离内淡入道路。注意需要 EasyRoads3D 透明着色器，或相应修改自定义着色器。
  • Fade Out Distance（淡出距离）[Pro]：选择最后一个标记时显示。可用于在 x 米距离内淡出道路。同样需要透明着色器。

额外设置：

  • Custom Vertex Color（自定义顶点颜色）：此信息可在自定义着色器中使用。

按钮：

  • Split Road at Selected Marker（在所选标记处分割道路）：在所选标记处切断道路并创建新的道路对象。
  • Insert I Connector（插入 I 连接器）[Pro]：可用于连接不匹配的道路类型、混合道路类型（如沥青路/泥土路）、在某段上更改道路材质，或将长道路拆分为较短段以获得更好性能。详见下文 I 连接器。

其他标记选项：R 键移除所有所选标记；“I"键在场景中鼠标位置插入标记。更多快捷键见相关章节。

标记侧边对象设置

在上方主要侧边对象部分为道路激活侧边对象后，该侧边对象将添加到每个标记可用的下拉菜单中。

选择侧边对象后将显示标记特定控件。当侧边对象在侧边对象管理器中设置为相对于道路中心创建，或侧边对象管理器中的"Dual Sided”（双面）控件未激活时，将显示单组控件。当侧边对象相对于道路左侧或右侧生成且"Dual Sided"激活时，将显示两组控件，道路每侧各一组。

  • Selected Side Object（所选侧边对象）：以下控件将影响此下拉菜单中当前所选的侧边对象。
  • Active（激活）：此侧边对象在此标记的激活状态。
  • Start Offset（起始偏移）：侧边对象应开始的位置，相对于标记。当前一个标记未激活时此选项启用。例如用于将桥梁与地形对齐。也可使用场景视图中的滑块设置此值。
  • End Offset（结束偏移）：侧边对象应结束的位置，相对于下一个标记。当后一个标记未激活时此选项启用。也可使用场景视图中的滑块设置此值（当前一个标记未激活时可见）。

    提示： 例如使用 R 键切换关闭标记位置手柄，以避免与滑块手柄干扰。

  • X Position（X 位置）：默认继承侧边对象管理器中设置的"X Position"值，可按标记调整。
  • Rotation Angle（旋转角度）：可按标记对侧边对象应用固定旋转。例如为围栏或护栏等待侧对象添加损坏效果。
  • Rotation Distance（旋转距离）：旋转应用的距离。
  • Rotation Center Position（旋转中心位置）：旋转中心相对于所选标记的偏移。

添加形状到地形 Splatmap [Pro]

场景中每条道路的形状都可以烘焙到地形 splatmap 中，这是一种以自然方式将道路与地形混合的有效方法。

  • Activate（激活）：为此道路激活 splatmap 混合。
  • Splatmap Texture（Splatmap 纹理）：列出所有可用的地形 splat map 纹理，选择要使用的纹理。
  • Expand（扩展）：增大道路形状的大小。值为整数，表示 splatmap 索引数量。
  • Smooth Level（平滑级别）：将所选纹理与原始地形 splatmap 逐渐混合。值为整数，表示 splatmap 索引数量。
  • Opacity（不透明度）：设置道路形状与原始地形 splatmap 的混合强度。为 0..1 范围的浮点数。

在构建模式中烘焙道路形状到地形 splatmap，确保在构建设置中勾选"Update Terrain Splatmaps”（更新地形 Splatmap）。

注意： 以上设置也可应用于道路类型。Splatmap 烘焙设置将自动分配给该道路类型的新实例。

相机飞越

相机飞越功能有助于快速浏览所选道路。

  • Position（位置）：位置滑块沿道路移动场景相机。
  • Height（高度）：设置场景相机在道路上方的高度。
  • Cam Speed（相机速度）：场景视图相机动画的动画速度。
  • Play（播放）：沿道路动画场景视图相机。按下播放按钮后动画开始，再次按同一按钮停止动画。

附加交叉口 [Pro]

交叉口可以通过选择任意标记直接附加到道路。在交叉口/连接选项卡 （Inspector 中左数第三个）中，将显示所有可用的交叉口/连接对象。点击要附加到所选标记的对象。当交叉口插入到道路中间某处时，道路将被分割为两个道路对象。

此外，交叉口对象（特别是环岛对象）也可以通过同一选项卡直接实例化到场景中。未选择道路时，所有交叉口和连接预制体都可见。选择要在场景中实例化的对象，按住 SHIFT 键并在场景中点击要放置对象的位置。如果要多次实例化同一对象，可以重复 SHIFT + 点击。

连接控件 [Pro]

在场景中实例化连接或选择场景中现有连接后，Inspector 将显示连接属性和控件。

  • Position（位置）：连接的位置。
  • Rotation（旋转）：连接的旋转。
  • Rotate Connection（旋转连接）：根据已连接的道路和可用的空闲连接，此按钮将旋转预制体并交换连接。例如用于 T 型交叉口旋转或镜像交叉口。
  • T-Crossing（T 型交叉口）：在动态 X、T 型交叉口上激活，将根据此状态构建预制体。
  • Sidewalks（人行道）：在动态连接预制体上激活，设置全局人行道状态。
  • Delete Connection（删除连接）：从场景中移除连接。
  • Select Connection in Hierarchy（在层级中选择连接）：选择实际的旋转游戏对象。对于动态交叉口，将显示连接属性。

I 连接器 [Pro]

I 连接器与其他连接预制体的不同之处在于，它不是物理上存在于资源文件夹或连接预制体选项卡（Inspector 中左数第三个）中的预制体。

I 连接器可以通过标记部分中的"Insert I Connector"按钮附加到任何标记。如果不是所选道路的第一个或最后一个标记，道路将在所选标记处分割为两条道路，I 连接器位于两者之间。

I 连接器可用于：

  1. 混合道路，例如沥青路和泥土路。
  2. 在特定路段使用不同材质。
  3. 连接不匹配的道路类型。
  4. 将道路切成片段以进行遮挡剔除或流式加载道路网络段（通常与地形瓦片相关）。

I 连接器属性

道路 1 和道路 2：

  • Road Type Preset（道路类型预设）：已连接道路的道路类型。如果未连接道路，从此连接拉出的新道路将使用所选道路类型。
  • Material（材质）：分配给道路的材质。目前无功能。
  • Connector Distance（连接器距离）：默认情况下 I 连接器连接两条道路。设置连接器距离后，可以调整道路宽度和/或混合不同道路类型。
  • Stretch Width（拉伸宽度）：在连接距离上调整宽度。选项有线性（Linear）、指数（Exponential）和平滑（Smooth）。“Stretch to fit"将自动设置拉伸级别以匹配另一条道路的宽度。
  • Sub Division（细分）：拉伸可能导致锯齿状纹理。细分级别在此很有用，值越高锯齿效果越小。

额外设置：

  • Resolution（分辨率）：连接的几何分辨率。
  • Transition Type（过渡类型）：过渡类型，[None]（无）、[Blend textures]（混合纹理）或 [Texture Transition]（纹理过渡）。根据选择显示以下选项。

Blend Textures（混合纹理）：

  • Blend Textures（混合纹理）：激活混合选项。
  • Blend Distance（混合距离）：纹理混合的距离。
  • Blend Section（混合段）：混合可以在主连接（道路 1）、道路 2 或两段上进行。一般使用较宽的道路，例如较宽的沥青路，泥土路在沥青段上混合。
  • Blend Presets（混合预设）：尚未激活。旨在根据涉及的道路类型自动分配 I 连接器设置。
  • Blend Material（混合材质）：用于混合的材质。示例着色器有"ER Dual Road Blend”（用于两种不同道路类型）和"ER Single Road Blend"（用于相同道路类型）。“Build"按钮将根据已连接道路对象上的材质自动设置材质，前提是这些着色器具有标准 Unity 属性名（_MainTex、_BumpMap、_Metallic、_Glossiness、_Color 等）。

Texture Transition（纹理过渡）：

  • Transition section（过渡段）：在两条道路中的哪一条上进行过渡。
  • Transition Material（过渡材质）：应用于过渡的材质。“Build"按钮将根据已连接道路对象上的材质自动设置材质，前提是着色器具有标准 Unity 属性名。
  • Swap Direction（交换方向）：交换 UV 坐标以反转过渡。
