EasyRoad3D-已知问题与说明

交叉口附近道路三角形重叠

当道路与交叉口的角度过锐时，三角形可能重叠。这尤其发生在道路起点左侧。目前的解决方法是将第一个标记放在交叉口附近，或减小道路与交叉口的角度。

道路与 T 型交叉口之间的小间隙

这与"交叉口 > 常规设置 > Activate Bending"（激活弯曲）有关。在道路网络刷新和更新特定道路类型的场景实例后可能发生。T 型交叉口形状会被重置，不再跟随道路弯道。此问题将修复。目前稍微移动交叉口即可更新；或者如果不需要此功能，可以关闭"Activate Bending"。

环岛未正确连接到第一个或最后一个标记

目前请避免将环岛附加到所选道路的第一个或最后一个标记。改用另一种方式向场景添加交叉口：从 Inspector 中的主 EasyRoads3D 工具栏选择交叉口连接预制体选项卡 。 从可用交叉口预制体列表中选择要实例化的环岛，按住 SHIFT 键并在场景中点击要放置环岛的位置。现在可以将道路连接到预制体，或通过拖动红色环岛连接手柄来开始新道路。完整信息见交叉口章节。

运行时 API

这与使用运行时 API 创建的道路网络有关。为保留原始地形数据，请务必备份场景中的地形对象！

一般来说恢复地形工作良好，但曾发生过退出播放模式后地形仍停留在构建状态，使道路形状留在地形中。这特别发生在播放模式中将焦点放在场景视图窗口时。请在您端测试，如果打算使用运行时 API 生成道路网络，请保留地形备份。

分割道路后选中错误标记

将一条道路分割为两条道路并选中新创建道路的第一个标记后，实际选中的是原始道路的第一个标记。

发生这种情况时，只需点击地形取消选择标记，再次选择它应该正常工作。此问题将被调查。

连接两条道路后侧边对象出现在道路另一侧

当两条道路中某一条的标记被反转时发生，即道路指向相反方向。一种解决方法是为道路左右两侧链接相同的侧边对象。

颠簸道路与圆形控制器类型

在圆形段上，当"起伏 Y 偏移"使用大于 0.5 或小于 -0.5 的值时，该段的道路几何可能无法正确创建。值越高越可能发生。这将进一步优化。目前可以尝试稍微移动标记，或将该段的起伏值向 0 减小。对于道路来说，起伏值大于 0.5 或小于 -0.5 相当不常见。但在圆形段上可能发生，例如相当颠簸的自行车道。

撤销 / 重做

撤销"连接两条道路"： 本身工作良好，撤销/重做也应良好，除非此操作在撤销栈较深处。但撤销后，其中一个道路形状可能未更新。移动标记后会自动修正（移动标记很可能就是下一步）。此问题将被调查。

使用 Shift + J 连接两条道路时，撤销工作良好，但重做可能导致重复错误并可能导致材质被重置。执行 2 次撤销操作应可解决。

撤销"从连接分离道路"： 初看工作良好，但之后移动连接对象不会调整附加的道路。取消选择 > 重新选择道路网络应可修复。此问题将被调查。

连接预制体变换更改后撤销： 当从撤销栈较深处调用此操作时，附加的道路可能不更新。要修复，选择连接预制体并稍微移动它，使附加道路更新。

撤销"删除连接"后： 尚未生效。

取消选择道路网络后撤销： 取消选择道路网络后执行撤销不可靠。更改会被撤销，但道路网格可能不更新。目前可以选择道路并移动标记强制更新。

构建模式： 不建议在切换到构建模式后使用撤销。应使用"Back to Edit Mode"（返回编辑模式）按钮切换回编辑模式。

动态交叉口、人行道和 I 连接器

目前避免在道路另一端通过 I 连接器连接的情况下，更新交叉口上的人行道设置。作为临时解决方法，可以先将道路从 I 连接器断开，更新人行道后再重新连接到 I 连接器。
