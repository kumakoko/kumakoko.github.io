Streamer 类的作用分析

Streamer 是 WorldStreamer 2 插件的核心流送控制器，负责在大型开放世界中根据玩家位置异步加载/卸载场景瓦片（Scene Tiles），是整个场景流送系统的"大脑"。

一、核心定位

Streamer 继承自 MonoBehaviour（或 AtavismStreamer，当定义 AT_STREAMER2 时用于 Atavism MMO 框架），挂在场景中的 _Streamer_Major / _Streamer_Minor 物体上。它不直接存储瓦片数据，而是作为调度者，协调多个子系统完成流送。

二、主要职责

1. 玩家位置追踪 & 网格判定

  • 通过协程 PositionChecker() 每隔 positionCheckTime（默认 0.1 秒）轮询玩家位置
  • CheckPositionTiles() 调用各 SceneCollectionManager.CheckPosition 判断玩家是否跨入新的网格单元
  • 若发生变化，则触发加载与卸载

2. 场景瓦片加载

  • SceneLoading() 以螺旋遍历方式扫描玩家周围 loadingRange 范围内的瓦片，将未加载的瓦片加入 scenesToLoad 队列
  • 支持环形流送（useLoadingRangeMin 挖空中心区域）
  • 支持世界循环（looping，通过 mod 取模实现坐标回绕）
  • LoadLevelAsyncManage() 在 Update 中按优先级排序队列，受 maxParallelSceneLoading 限制并发数，并通过 sceneLoadWaitFrames 做帧间隔控制

3. 场景瓦片卸载

  • SceneUnloading() 延迟 destroyTileDelay 秒后执行，遍历已加载瓦片，超出 deloadingRange 的加入销毁列表
  • 支持跨层联动卸载（unloadRangeConnect，当某层瓦片加载时卸载另一层对应位置瓦片）
  • 卸载后调用 TerrainNeighbours.CreateNeighbours() 修复地形 LOD 边界

4. 资源卸载

  • UnloadAssets() 以协程节流方式调用 Resources.UnloadUnusedAssets()，间隔 waitTillNextUnload（20 秒），避免频繁调用造成卡顿

5. 世界原点重置（Floating Origin）

  • 集成 WorldMover，玩家移动一定距离后将整个世界反向平移，避免浮点数精度问题
  • currentMove 记录累积偏移量，加载瓦片时据此修正位置

6. 加载进度 & UI

  • tilesToLoad / tilesLoaded / LoadingProgress 提供加载进度
  • 可选显示 UILoadingStreamer 加载界面

三、协作关系

协作类职责
SceneCollectionManagerScriptableObject，存储瓦片配置（尺寸、范围、场景名列表），维护 scenesArray 字典和 loadedScenes 列表
SceneSplit单个瓦片的数据结构（位置、场景名、加载状态、循环偏移）
StreamerLoadingManager实际执行 SceneManager.LoadSceneAsync/UnloadSceneAsync，管理加载/卸载状态机，避免同时操作
WorldMover世界原点重置
TerrainNeighbours地形相邻关系修复

四、典型工作流

Start()
  └─ PrepareScenesArray()  // 构建瓦片字典
  └─ PositionChecker() 协程
       └─ 每 0.1s: CheckPositionTiles()
            ├─ 玩家跨格? 
            │    ├─ SceneLoading()  → 螺旋扫描 → scenesToLoad 队列
            │    ├─ SceneUnloading() (延迟) → 超范围瓦片 → 卸载队列
            │    └─ WorldMover.CheckMoverDistance()
Update()
  ├─ LoadLevelAsyncManage()  // 消费 scenesToLoad，按优先级+并发限制提交加载
  └─ loadingManager.Update()  // 执行实际异步加载/卸载

五、总结

Streamer 是整个场景流送系统的调度中枢：它以玩家位置为驱动，以网格为单位，通过螺旋加载 + 范围卸载的策略，实现了一个可配置、支持多层/循环/环形流送的大型世界场景管理系统。实际的异步 IO 操作委托给 StreamerLoadingManager，瓦片元数据存储在 SceneCollectionManager 中，Streamer 本身专注于**“何时加载/卸载哪些瓦片"的决策逻辑**。
