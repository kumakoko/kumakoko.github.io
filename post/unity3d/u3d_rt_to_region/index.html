Unity3D的GL.GetGPUProjectionMatrix函数

如Unity官方文档所描述：此函数是把C#层的Camera类获取到的投影矩阵（Camera.projectionMatrix），转换成可以传递给GPU shader使用的投影矩阵。在 Unity 中，投影矩阵遵循 OpenGL风格约定（参见《Unity3D内建着色器源码剖析》第1.2.2节的公式1-34和公式1-36）。但在其他平台，比如Direct3D平台，遵循OpenGL风格的投影矩阵，必须转换成Direct3D风格的矩阵才能满足Direct3D API 要求。GL.GetGPUProjectionMatrix函数就是做这个工作。

使用此函数计算得到的最终投影矩阵，将与Unity3D的内置着色器变量UNITY_MATRIX_P一样。

GL.GetGPUProjectionMatrix函数还有一个参数bool renderIntoTexture。表示要指明这个投影矩阵是否要作用到render texture上。这是因为render texture的纵向坐标（V坐标）的原点，在不同平台上也有不同的实现。所以在创建投影矩阵的时候，也要考虑到这点。

将一张贴图贴到render texture的指定区域可以如下实现：

// RectInt position 用来
private void DrawTexture(Texture source, RenderTexture target, RectInt position)
{
    if (source == null || target == null || m_DrawTextureShader == null)
        return;

    // 初始化绘制材质
    if (m_DrawTextureMateral == null)
        m_DrawTextureMateral = new Material(m_DrawTextureShader);
        
    // 构建变换矩阵。这个矩阵用于将纹理从源坐标空间转换到目标RenderTexture的屏幕坐标空间。
	// 它是一个 4x4 的仿射变换矩阵，目的是将纹理的UV坐标映射到屏幕上的指定区域。
	// 可以理解为一个正交投影矩阵
	// 它的构建基于输入的 RectInt position，将其坐标映射到OpenGL的标准化设备坐标系(NDC)中，
	// 即在 [-1, 1] 的范围内。
	
	// l（left）、r（right）、b（bottom）、t（top）分别是矩形左、右、下、上的边界，转换为
	// NDC 坐标。通过 position 的 x、y、width、height 计算出这些边界：
	// l：position.x 相对于 target.width 的比例减去 1，得到 [-1, 1] 范围的左边界。
	// r：position.x + position.width 转换为 NDC 范围中的右边界。
	// b 和 t 类似地通过 position.y 和 position.height 转换为下边界和上边界。
	// 然后，构建一个仿射变换矩阵 mat，其中：
	// mat.m00（第一列第一行）：水平缩放因子，r - l，表示矩形在水平轴的缩放。
	// mat.m03（第一列第四行）：水平偏移，l，表示左侧的边界位置。
	// mat.m11（第二列第二行）：垂直缩放因子，t - b，表示矩形在垂直轴的缩放。
	// mat.m13（第二列第四行）：垂直偏移，b，表示底部的边界位置。
	// mat.m23：设置为 -1，表示深度的偏移，确保该图像在正确的深度层绘制。
	// mat.m33：设置为 1，表示齐次坐标。
	
    float l = position.x * 2.0f / target.width - 1;
    float r = (position.x + position.width) * 2.0f / target.width - 1;
    float b = position.y * 2.0f / target.height - 1;
    float t = (position.y + position.height) * 2.0f / target.height - 1;
    var mat = new Matrix4x4();
    mat.m00 = r - l;
    mat.m03 = l;
    mat.m11 = t - b;
    mat.m13 = b;
    mat.m23 = -1;
    mat.m33 = 1;

    // 绘制贴图
    m_DrawTextureMateral.SetMatrix(Shader.PropertyToID("_ImageMVP"), GL.GetGPUProjectionMatrix(mat, true));
    target.DiscardContents();
    Graphics.Blit(source, target, m_DrawTextureMateral);
}
