YooAsset HostPlayMode（联机热更模式）完整热更新流程

HostPlayMode是手游最常用模式，三套FileSystem协同工作

  1. BuildinFileSystem：安装包内StreamingAssets/yoo首包内置资源（只读兜底）
  2. CacheFileSystem：手机沙盒可读写目录，存放已经下载的AB包、清单
  3. RemoteFileSystem：访问CDN远程服务器下载补丁资源

前置：打包阶段输出补丁包，包含：version文件、PackageManifest(清单)、全部.bundle，全部上传CDN。

整体流程图（客户端启动后）

游戏启动 → YooAssets全局初始化 → Package初始化
→ ①请求远端PackageVersion版本号
→ ②更新本地Manifest资源清单
→ ③创建下载器，对比MD5/Crc，生成待下载列表
→ ④多线程断点下载AB包到沙盒缓存
→ ⑤切换激活新清单，完成更新
→ （可选）清理沙盒废弃缓存文件
→ 业务层LoadAssetAsync加载资源，进入游戏

分步详解（运行时每一步干什么）

步骤1：初始化YooAsset与Package

//全局初始化
YooAssets.Initialize();
var package = YooAssets.CreatePackage("DefaultPackage");

//HostPlayMode参数：内置文件系统、缓存文件系统、远程CDN文件系统
var hostParam = new HostPlayModeParameters();
hostParam.BuildinFileSystemParameters = FileSystemParameters.CreateDefaultBuildinFileSystemParameters();
hostParam.CacheFileSystemParameters = FileSystemParameters.CreateDefaultCacheFileSystemParameters(remoteService);
hostParam.RemoteFileSystemParameters = FileSystemParameters.CreateDefaultRemoteFileSystemParameters(remoteService);

await package.InitializeAsync(hostParam);
  • 初始化逻辑：优先读取沙盒缓存里的Manifest；沙盒没有就读取安装包StreamingAssets内置Manifest，拷贝到沙盒作为基础版本。此时还没有联网检查新版本，只是把本地旧版本加载就绪。

步骤2：RequestPackageVersionAsync 请求远端版本号

var verOp = package.RequestPackageVersionAsync();
await verOp.Task;
string remoteNewVersion = verOp.PackageVersion;
  • 向CDN请求version版本文件（很小的文本文件，记录当前线上Package的版本字符串）。
  • 拿到线上最新版本号；网络失败在这里弹窗提示重试。

⚠️version文件是整个热更的入口，每次打包补丁包都会生成新version。

步骤3：UpdatePackageManifestAsync 更新资源清单

var manifestOp = package.UpdatePackageManifestAsync(remoteNewVersion);
await manifestOp.Task;
  1. 拿远端版本号，去CDN下载对应的PackageManifest清单文件（几KB）。
  2. Manifest清单记录该Package下全部AB包、每个资源归属哪个AB、每个AB的MD5、大小、依赖关系。
  3. YooAsset对比：沙盒缓存已有哪些bundle、内置首包有哪些bundle。
    • 相同MD5：直接复用（不管来自沙盒缓存，还是来自APK内置StreamingAssets）
    • MD5不一致 / 本地不存在：标记为需要下载

✨增量更新的核心就在Manifest对比，不会全量下载，只下载变更/新增bundle。

步骤4：CreateResourceDownloader 创建下载器

var downloader = package.CreateResourceDownloader(maxConcurrency:8, retryCount:3);
  • 内部遍历新Manifest，筛选出本地缺失、MD5不匹配的AB，生成下载任务列表。
  • downloader.TotalDownloadCount、TotalDownloadBytes得到需要更新的文件数量、总大小，用来展示UI进度条。
  • 如果TotalDownloadCount=0 → 已是最新版本，跳过下载。

步骤5：BeginDownload 执行下载

downloader.OnDownloadProgressCallback = (total,cur,totalBytes,curBytes)=>{
    //更新UI进度
};
downloader.OnDownloadErrorCallback = (filename,err)=>{
    //单个文件下载失败回调
};
await downloader.BeginDownload().Task;
  • 从CDN下载bundle，写入沙盒缓存目录；支持断点续传、多并发、失败重试。
  • 下载成功的bundle保存在沙盒，优先使用沙盒资源，覆盖首包内置资源（即使APK里还有旧bundle，也会用沙盒新的）。

内置首包资源不会被修改，只读；更新全部发生在可写沙盒目录。

步骤6：更新完成，激活新清单，清理废弃缓存（可选）

下载全部成功后，当前Package已经切换到新版本Manifest，就可以正常加载资源。

⚠️YooAsset不会自动删除沙盒里旧的、不再被清单引用的bundle，会占用存储空间，建议更新完成后后台执行清理：

YooAssets.ClearUnusedCacheFiles();

该接口扫描沙盒，删除当前Manifest不再引用的旧bundle文件，释放磁盘空间。

步骤7：业务层加载资源

var handle = package.LoadAssetAsync<GameObject>("Prefabs/XXX");
handle.Completed += op=>{
    Instantiate(op.AssetObject);
    op.Release(); //必须释放句柄，引用计数管理内存
};

关键机制要点

  1. 资源查找优先级：沙盒缓存 > APK内置StreamingAssets > CDN下载

    • 如果沙盒已经存在MD5匹配bundle，直接用；没有，再看首包内置；都没有才去下载。
    • 首包里的资源，后续CDN更新后，沙盒会覆盖它，不需要重新打APK。

  2. Manifest的意义

    • Manifest属于Package级别，每个Package一份。
    • 热更本质就是：下载新版本Manifest，以新Manifest为准，补齐缺失的bundle。

  3. 失败场景处理

    • 请求版本失败：网络异常，弹窗重试。
    • 清单下载失败：重试；多次失败可降级使用本地旧版本。
    • 部分bundle下载失败：可以选择全部重试，或者提示玩家网络问题退出。

打包侧流程（开发/发版时）

  1. 在Collector配置Package/Group/Collector，设置PackRule分包规则。
  2. AssetBundleBuilder执行打包，生成补丁包输出目录。
  3. 可配置Copy Buildin File Option，把部分资源拷贝到StreamingAssets作为首包内置资源。
  4. 将补丁包全部文件（version、manifest、*.bundle）上传CDN对应平台目录。
  5. 发新版本补丁：重新打包，生成新version、新manifest，上传CDN，客户端下次启动就检测到更新。

容易踩坑

  1. CDN必须支持HTTP静态访问；WebGL需要配置跨域。
  2. Manifest不会包含Group、Collector，这些是编辑器配置，打包之后就消失了。
  3. 不要混淆PackageVersion（资源包版本字符串）和App版本号，二者独立。
  4. 下载完成不要忘记Release Handle，否则资源不会卸载，内存泄漏。
