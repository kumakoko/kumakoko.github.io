EasyRoad3D-已知问题与说明

交叉口附近道路三角形重叠

当道路与交叉口的角度过锐时，三角形可能重叠。这尤其发生在道路起点左侧。目前的解决方法是将第一个标记放在交叉口附近，或减小道路与交叉口的角度。

道路与 T 型交叉口之间的小间隙

这与"交叉口 > 常规设置 > Activate Bending"（激活弯曲）有关。在道路网络刷新和更新特定道路类型的场景实例后可能发生。T 型交叉口形状会被重置，不再跟随道路弯道。此问题将修复。目前稍微移动交叉口即可更新；或者如果不需要此功能，可以关闭"Activate Bending"。

环岛未正确连接到第一个或最后一个标记

目前请避免将环岛附加到所选道路的第一个或最后一个标记。改用另一种方式向场景添加交叉口：从 Inspector 中的主 EasyRoads3D 工具栏选择交叉口连接预制体选项卡 。 从可用交叉口预制体列表中选择要实例化的环岛，按住 SHIFT 键并在场景中点击要放置环岛的位置。现在可以将道路连接到预制体，或通过拖动红色环岛连接手柄来开始新道路。完整信息见交叉口章节。

运行时 API

这与使用运行时 API 创建的道路网络有关。为保留原始地形数据，请务必备份场景中的地形对象！

一般来说恢复地形工作良好，但曾发生过退出播放模式后地形仍停留在构建状态，使道路形状留在地形中。这特别发生在播放模式中将焦点放在场景视图窗口时。请在您端测试，如果打算使用运行时 API 生成道路网络，请保留地形备份。

分割道路后选中错误标记

将一条道路分割为两条道路并选中新创建道路的第一个标记后，实际选中的是原始道路的第一个标记。

发生这种情况时，只需点击地形取消选择标记，再次选择它应该正常工作。此问题将被调查。

连接两条道路后侧边对象出现在道路另一侧

当两条道路中某一条的标记被反转时发生，即道路指向相反方向。一种解决方法是为道路左右两侧链接相同的侧边对象。

颠簸道路与圆形控制器类型

在圆形段上，当"起伏 Y 偏移"使用大于 0.5 或小于 -0.5 的值时，该段的道路几何可能无法正确创建。值越高越可能发生。这将进一步优化。目前可以尝试稍微移动标记，或将该段的起伏值向 0 减小。对于道路来说，起伏值大于 0.5 或小于 -0.5 相当不常见。但在圆形段上可能发生，例如相当颠簸的自行车道。

撤销 / 重做

撤销"连接两条道路"： 本身工作良好，撤销/重做也应良好，除非此操作在撤销栈较深处。但撤销后，其中一个道路形状可能未更新。移动标记后会自动修正（移动标记很可能就是下一步）。此问题将被调查。

使用 Shift + J 连接两条道路时，撤销工作良好，但重做可能导致重复错误并可能导致材质被重置。执行 2 次撤销操作应可解决。

撤销"从连接分离道路"： 初看工作良好，但之后移动连接对象不会调整附加的道路。取消选择 > 重新选择道路网络应可修复。此问题将被调查。

连接预制体变换更改后撤销： 当从撤销栈较深处调用此操作时，附加的道路可能不更新。要修复，选择连接预制体并稍微移动它，使附加道路更新。

撤销"删除连接"后： 尚未生效。

Unity场景烘焙光照贴图FAQ

请尊重原作者的工作，转载时请务必注明转载自：kumakoko.github.io

1 切分.unity场景后共享使用光照贴图的问题

World Streamer 插件文档的Lighting Settings 选项中说：“这个Lighting Settings是为切分生成的场景设置的。可以为它们设置特定的光照选项，这样所有场景都会包含相同的 lightmap、烘焙 ambient 等设置。这可以避免流式加载过程中的警告和错误。它还可用于 切分的 Light Probe（光照探针） 并把它们分发到流式场景中”，这是不是指：所有的切分后的生成的场景，都用的是同一份光照贴图，即是切分前的大场景的那张光照贴图？

用户的理解基本正确，但需要厘清两个层面：

1.1. Lightmap 本身：确实是大场景烘焙的那一套，切分不会重烘

切场景时，每个 Renderer 身上的两个关键数据原样保留：

  • lightmapIndex——用哪张 lightmap 图集
  • lightmapScaleOffset——在该图集上的 UV 区域

所以切分后所有 tile 里的物体，采样的仍是切分前在 Work 大场景里一次性烘焙出来的 lightmap 资产。这样做的好处正是跨 tile 边界光照连续，不会出现每个 tile 各烘各的接缝和漏光。

1.2. 但 “same lightmap” 的重点是"引用和设置统一"，不是每场景复制一份贴图

Unity 每个场景自带一份 LightmapSettings / RenderSettings（ambient、fog、baked ambient 等）。大场景切成几十个 tile 后，如果某个 tile 丢失 lightmap 引用或设置不一致，运行时多场景叠加加载时就会出现 renderer references invalid lightmap 之类的警告，物体发黑。

这个 Lighting Settings 选项做的事，就是把同一份 lightmap 资产引用 + 相同的 ambient/fog 等设置写进每个生成的 tile 场景。磁盘上的 lightmap 纹理（exr / LightingDataAsset）只有一份，是被多个场景共享引用的资产，不是每场景各存一份。手册原文也说，初始设置直接取自当前 Work 场景，Work 场景设置正确的话其余项不用再动。

EasyRoad3D-侧边对象

简介

EasyRoads3D 包含一个附加功能，可以向道路网络添加额外对象，称为侧边对象（Side Objects）。这些对象可以沿道路对象全长生成，也可以仅为特定标记段激活。

侧边对象有三种类型：

  1. 网格类型（Mesh Type）侧边对象：沿道路实例化。示例：路灯、岩石构造、道路贴花或树列。
  2. 程序化侧边对象类型：基于一个预制体，该预制体将沿道路重建并重复。示例：护栏、围墙或电线。
  3. 形状类型（Shape Type）侧边对象：生成方式与程序化侧边对象类似，但侧边对象将根据形状编辑器窗口中定义的 2D 形状生成。可以是围墙，其他示例有路肩尘带、地形细节网格覆盖层，甚至河流。这是可能的，因为侧边对象系统本身就是一个框架，它也可用于创建场景中与道路无关的其他元素。

从 v3.2 开始，特定侧边对象段（如弯道中的护栏、挡土墙、桥梁和隧道）也可以根据一组规则和该区域的地形剖面自动生成。例如，当道路到地形的高度差大于特定值（隧道阈值高度）时创建隧道；当地形与道路的高度差小于指定阈值高度时创建桥梁；当道路以大于指定弯道阈值角度转弯，或道路边缘的地形低于指定阈值高度时，创建护栏和急转标志等道具；当道路一侧的地形低于指定阈值高度，或路段重叠时，创建挡土墙。

新侧边对象的创建和现有侧边对象的编辑在侧边对象管理器中进行。v3 中的侧边对象管理器可通过 Inspector 工具栏访问，右侧第二个选项卡

注意： EasyRoads3D 还包含将标记吸附到特定对象的选项。这可以用于您自己的资源/预制体，这些对象不一定跟随道路，但与道路交互，例如桥梁预制体。详见本页底部。

提示： 当场景中选中道路对象，且侧边对象管理器中当前所选侧边对象在此道路上激活时，场景视图窗口右下角会显示刷新图标。这可用于快速可视化此侧边对象在所选道路上的更改。底部的"Update Active Scene Instances"按钮将在所有道路上更新此侧边对象。

主侧边对象设置和选项

Inspector 中的侧边对象控件根据侧边对象类型和激活的选项显示。以下涵盖所有情况，先从主侧边对象设置开始。

按钮：

  • Create New Side Object（创建新侧边对象）：添加新侧边对象。
  • Add Project Side Objects（添加项目侧边对象）：场景中的所有新侧边对象既存储在场景中，也存储在资源文件夹（/Assets/EasyRoads3D/Resources/ERSideObjectsLog）中。当资源文件夹中有尚未添加到此场景的侧边对象时，此按钮激活。按钮将打开侧边对象导入器窗口，列出所有可用侧边对象。这样可以保持场景特定侧边对象列表清晰简洁。
  • Import Side Objects（导入侧边对象）：支持从另一个项目导入侧边对象。导入侧边对象 Unity 包后（见下文导出侧边对象），点击此"Import Side Objects"按钮，将打开侧边对象导入窗口。将带侧边对象预设的预制体拖入窗口，所有侧边对象将列出，可以选择要导入哪些。
  • Manage Project Side Objects（管理项目侧边对象）：从项目中永久移除侧边对象。
  • Export Side Objects（导出侧边对象）：导出侧边对象。可以选择要导出的侧边对象。点击导出按钮后，将提示设置创建预制体的位置和名称，应在资源文件夹内。此预制体及所有依赖项将导出为 Unity 包。

侧边对象工具栏：

侧边对象可分为 7 个选项卡。其中一些选项卡还显示类别特定设置，例如桥梁选项卡同时用于桥梁和隧道。

Selected Side Object（所选侧边对象）：

显示所有控件的侧边对象。

  • Delete Side Object（删除侧边对象）：从列表中移除侧边对象，同时从所有道路对象中移除。
  • Duplicate Side Object（复制侧边对象）：创建所选侧边对象的副本，适合创建道路左侧和右侧的变体。

场景选项卡 将显示当前道路网络的信息。您可以选择用于移动标记的手柄，选择道路或交叉口对象后，Inspector 将显示该对象的信息。

道路属性

在[添加道路]或选择现有道路的标记（蓝色球形手柄）后，将显示道路属性：

  • 道路名称右侧的小锁图标可用于锁定道路并禁用所有控件。

  • 道路名称下方是道路统计信息：总长度/距离（米或公里，基于 1 个 Unity 单位 = 1 米）、总顶点数和三角形数。

  • 控件分为 6 个可折叠子菜单。每个子菜单可单独打开；按住 Shift 键选择子菜单时，将关闭所有其他打开的子菜单。

  • 道路名称右侧的锁图标可锁定所有道路设置，锁定状态下道路无法编辑。结合场景设置中的"排除已锁定对象"选项，这也可用于在场景视图中隐藏道路手柄。

  • 问号按钮将打开相关的在线文档。

道路设置

可以显示所有道路设置控件（下图 UI），也可以将道路设置 UI 最小化为最常用控件（上图 UI）。点击底部的"Show More +“将显示所有控件。

主要设置：

  • Road Name（道路名称）：道路的名称。
  • Road Type（道路类型）：所选道路类型。只要道路未连接到交叉口，就可以更改为任何其他道路类型；否则只能更改为形状设置相似、节点数量也与交叉口连接形状匹配的道路类型。
  • Closed Track（闭合轨迹）：将道路循环闭合，非常适合生成赛道。
  • Road Width（道路宽度）：道路宽度。分配了道路类型时此字段不显示，此时可在"常规设置 > 道路类型"中更改道路宽度，这样基于该道路类型的所有道路实例和交叉口连接的宽度都可以即时更新。

细节设置：

  • Sub Segments（子分段）[Pro]：可用于细分道路网格以获得更多细节。注意动态交叉口尚不支持此功能。分配道路类型时此字段不会被禁用。
  • Resolution（分辨率）：以米为单位的几何分辨率。(**意思是说沿着道路的方向，相邻两个顶点的间隔为多少米？**)
  • Angle Threshold（角度阈值）[Pro]：可用于优化道路几何形状，同时保持弯道细节。尝试约 5 的值，并将道路分辨率提高到 10 或 20，顶点/三角形数量将显著下降。一般不建议使用低于 4 或 5 的角度阈值，除非追求高清晰度。
  • Road Smoothness（道路平滑度）[Pro]：
    • Bumpiness Y Offset（起伏 Y 偏移）：道路的平滑度，可通过最小/最大值控制。
    • Bumpiness Distance（起伏距离）：距离，可通过最小/最大值控制。
    • Random Tilting Angles（随机倾斜角）：为道路添加额外倾斜，可通过最小/最大值控制。
    • Tilting Distance（倾斜距离）：倾斜发生的距离。
  • Follow terrain Contours（跟随地形轮廓）[Pro]：道路将自动调整以适应地形形状，这将大大加快工作流程，因为需要的标记更少。
  • Contour Threshold（轮廓阈值）[Pro]：值越低，道路越贴合地形形状；高速公路等道路使用更高值。这是一个 DelayedFloatField，更改值后按 Enter 更新道路。

EasyRoad3D-常规设置

简介

常规设置选项卡 包含一组用于改进场景工作流程、控制地形对象的选项，还允许通过导入 OSM 或 KML 道路数据自动生成道路网络。

本页包含以下章节：

  • 场景设置
  • 道路类型
  • 连接预制体（交叉口、环岛和自定义预制体）
  • 默认材质
  • LOD 组
  • 地形管理
  • 导入道路数据

场景设置

  • Default Indent（默认缩进）：控制地形变形。默认值基于地形的 heightmapscale（尺寸与高度图分辨率之比），以确保根据道路和交叉口形状准确地平整地形。可选地增大这些值。Indent 值表示从道路边缘向外延伸到地形点的距离，该地形点将被平整到与道路在该点相同的高度，以保证最佳的地形变形效果。此值可以按标记逐个调整，但不能低于场景最小缩进值。不同的道路类型也可以设置不同的默认缩进值。
  • Default Surrounding（默认环绕）：默认环绕值表示在缩进位置处地形高度被平整到当前地形高度的距离。
  • Max Indent/Surrounding（最大缩进/环绕）：此值将用作所选标记的缩进/环绕滑块控件的最大值。
  • EasyRoads3D Layer（EasyRoads3D 图层）：默认情况下 EasyRoads3D 内部使用图层 31 进行后台操作，可以在此处更改。
  • Build Side Objects in Edit Mode（在编辑模式下构建侧边对象）：如果您更希望仅在构建模式下构建实际的侧边对象游戏对象，可以关闭此选项。
  • Use Light Probes（使用光照探针）：这将切换生成的道路网格渲染器上的"使用光照探针"选项。
  • Enable Back to Edit Mode without Terrain Restore（允许返回编辑模式而不恢复地形）：这是根据要求添加的，切换回编辑模式时，地形将不会恢复到切换到构建模式之前的原始状态。请谨慎使用！

场景视图设置

  • Highlight Selected Road（高亮所选道路）：高亮显示所选道路。在编辑模式下，当道路部分被地形覆盖时，这有助于在丘陵地区可视化道路。
  • Highlight Indents（高亮缩进区）：高亮显示缩进区域，即被平整到与道路相同高度的地形区域。
  • Highlight Surrounds（高亮环绕区）：高亮显示地形区域，在该区域上高度从道路高度逐渐过渡到原始地形高度。
  • Hide White Surfaces（隐藏白色表面）：隐藏道路和连接对象周围的白色表面。根据道路着色器的不同，这些白色表面可能会透过道路渲染出来。可以通过将 /Assets/EasyRoads3D/Resources/Materials/surfaceMaterial 上的 Offset 值向 0 减小来调整。
  • Enable Side Object Handles（启用侧边对象手柄）：在场景视图中显示手柄，例如用于控制侧边对象的起始和结束偏移。也可以使用 H 键。
  • Display Critical Areas（显示关键区域）：Unity 地形对象以 0 到 1 之间的小数存储地形高度数据，因此无法应用负高度值。接近或低于 0 值的部分将以红色手柄显示。这可以用来快速复查这些关键区域，确保地形不会穿透道路。
  • Only Display Markers Selected Road（仅显示所选道路的标记）：选中道路对象时，仅显示所选道路的蓝色标记。
  • Marker Handle Size（标记手柄大小）：控制场景视图中蓝色标记手柄的大小。
  • Marker Display Distance（标记显示距离）：控制显示手柄的最大距离。
  • Exclude Locked Objects（排除已锁定对象）：开启后，已锁定的对象将不显示标记手柄。
  • Mesh Terrain（网格地形）：或者，您可以使用网格地形代替 Unity 地形对象。网格地形不会根据道路形状变形。
  • Global Grid（全局网格）[Pro]：道路标记和连接预制体将吸附到网格，这对于城市或城镇环境很有用。
    • Grid Cell Size（网格单元大小）：单元大小
    • Grid Display Size（网格显示大小）：网格的可视化大小，焦点为窗口中心
    • Grid Rotation（网格旋转）：全局旋转
    • Grid Color（网格颜色）：网格单元轮廓的颜色
    • Local Grids（局部网格）：可以创建局部网格。当场景中需要不同的网格方向（旋转）或单元大小时很有用，控件与全局网格相同。
  • Scene Objects Control（场景对象控制）：默认情况下，Unity 会在点击场景中的对象时选中它。为了在添加标记或选择道路/交叉口对象时保持道路网络处于选中状态，对地形的点击事件会被拦截。其他大型对象（如水面）可能会干扰，它们在被点击时会被选中。可选地，可以通过从层级窗口拖放到"Add Object"槽中来添加此类对象。与地形对象一样，双击仍然会选中该对象。
  • Refresh Road Network（刷新道路网络）：重建并清理道路网络。

道路类型 [Pro]

特别是在构建包含不同道路类型的复杂道路网络时，建议在场景中实际构建道路之前设置道路预设。这些预设在向场景中添加新道路或设置交叉口/连接对象时可用，这是确保道路类型外观一致并与关联的交叉口类型匹配的简便方法。EasyRoads3D 道路类型也可以链接到 OSM 道路类型。

EasyRoad3D-交叉口

简介

EasyRoads3D v3 的新功能之一是支持交叉口。

EasyRoads3D 包含两种类型的交叉口：动态交叉口/连接预制体和自定义交叉口/连接预制体。动态交叉口/连接预制体由脚本驱动，可根据您的要求自定义宽度、人行道、材质等。自定义交叉口/连接预制体是基于您自己网格的预制体，可用于添加当前尚未支持的任何类型的交叉口或道路连接。它们与道路的交互方式与内置预制体相同——可以像动态预制体一样附加道路和从中拉出道路。

层级

在 v3 中，所有交叉口都是"Connection Objects"（连接对象）的子对象，而"Connection Objects"是主道路网络游戏对象的子对象。

在场景中创建交叉口

在场景中添加交叉口有三种方式：

方式一： 选择道路的任意标记，然后在 Inspector 中选择交叉口/连接选项卡 。所有匹配的动态和自定义预制体将列出。点击其中一个连接预制体，该预制体将自动连接到所选标记。

注意： 根据人行道状态和人行道类型（如果确实涉及人行道），如果人行道设置不同，附加所选预制体可能无法成功。

方式二： 在 Inspector 中选择同一个交叉口选项卡 ，但不选中任何道路。此时将列出所有可用的交叉口类型。选择要直接添加到场景的类型，它会高亮显示。在场景中要放置该交叉口的位置 SHIFT + 点击，交叉口将在鼠标位置自动实例化。

如果已选中道路且只显示匹配的预制体，而您实际想添加另一个预制体，可以点击顶部附近的"Instantiate New Connection Prefab"（实例化新连接预制体）按钮。这将取消选中道路，并如上所述显示所有预制体。

方式三： 通过将标记捕捉到其他路段来添加交叉口。可以是同一条道路或另一条道路，可以是任意标记。将所选标记移到另一个路段上时，如果存在匹配的连接预制体，捕捉位置将以蓝色高亮显示。支持不同道路类型，例如演示包中的铁路道口，只要在匹配场景情况的位置存在具有匹配道路类型的预制体即可。

注意： 当涉及与所涉及交叉口设置不完全匹配的自定义人行道设置时，第三种捕捉方式不起作用。在这种情况下，可以选择另一条道路上当前所选道路应连接到的标记，在该点插入交叉口，然后再连接最初选中的道路。

从交叉口连接拉出新道路

将场景相机移到某个交叉口实例上，您会在每个可用连接处看到绿色手柄。将鼠标移到其中一个手柄上，将出现黄色矩形移动手柄。点击并拖动即可从此连接拉出一条新道路。该道路将自动继承该特定交叉口连接的所选道路类型设置，包括相关道路类型可能已激活的侧边对象。

提示： 从连接拉出一条新道路后，只要没有激活人行道，就可以在该道路的 Inspector 中更新道路类型。

将现有道路连接到交叉口

非闭合道路的第一个和最后一个标记可以连接到交叉口连接，前提是道路类型匹配，或者至少道路形状与连接匹配。

当道路另一端已连接到交叉口时，所有与所选道路几何形状不匹配的交叉口连接将以红色手柄显示。道路无法连接到这些连接；道路只能附加到带有绿色手柄的连接。

为了避免连接顶点位置略有不同的[自定义交叉口]显示为红色，目前仅检查连接形状的顶点数。

道路类型不必与连接关联的道路类型匹配，但道路形状（顶点数）应匹配。

交叉口定位

要更改交叉口位置，点击中心黄色手柄选中预制体。按 M 键（移动手柄）或 W 键（位置 Gizmo）显示偏好的位置手柄/Gizmo。现在可以移动交叉口，附加的道路将适应更新后的位置。

交叉口对齐

将新交叉口附加到道路时，交叉口将沿相应方向对齐。该连接将自动继承对齐优先级。每当更改已连接道路的形状时，交叉口将相应对齐。具有对齐优先级的连接在其前方以白色手柄高亮显示。

选中交叉口预制体时（点击中心黄色球形手柄），您会在每个连接起点处的道路中心看到额外的灰色对齐手柄（见下图）。可以用它来更改具有对齐优先级的连接，也可以点击白色活动手柄来禁用该交叉口的自动对齐。

人行道控制

动态交叉口预制体完全支持人行道。[交叉口预制体]默认创建时可启用人行道。人行道激活状态可以按交叉口连接和按交叉口连接拐角分别自定义。

选中交叉口预制体时（点击中心黄色手柄），您会在每个交叉口拐角内看到 3 个绿色球形手柄（见上图）。当该拐角的人行道未激活时，3 个手柄都将为白色（见上图）。中间手柄控制该交叉口拐角上人行道段的可见性；外侧两个手柄控制已连接道路上人行道的激活状态。

EasyRoad3D-地形控制

概述

EasyRoads3D 将自动调整地形形状和植被以匹配创建的道路网络。本节说明所有选项，以及如何根据项目特定需求优化系统。

地形变形

要根据道路网络形状平整地形，从 Inspector 中的主 EasyRoads3D 工具栏激活地形选项卡 。

平整地形之前，有若干选项可供选择，以在创建道路网络时改善性能/工作流程。

  • Target Terrain(s)（目标地形）：如果场景中有多个地形对象，可以一次平整所有地形，也可以从下拉菜单选择其中一个地形对象，或按 CTRL + ALT + 点击地形。特别是在场景特定区域工作和测试期间，建议从下拉菜单选择该地形，这将节省宝贵时间。
  • Selected Road Objects Only（仅所选道路对象）：仅调整所选道路对象覆盖区域的地形。这在处理特定道路对象时快速测试很有用。
  • Remove Trees（移除树木）：移除受道路网络影响的树木。
  • Remove Detail Objects（移除细节对象）：移除受道路网络影响的细节对象。
  • Update Terrain Splatmaps（更新地形 Splatmap）：根据每个道路对象的 splatmap 设置将道路形状混合到地形中。
  • Add Side Object Vegetation（添加侧边对象植被）：将所有链接到地形树原型的侧边对象树木添加到相应的地形对象。
  • Calculate Road Tangents（计算道路切线）：为道路、交叉口和侧边对象网格数据添加额外切线信息，使用凹凸着色器时需要。
  • Calculate Lightmap UVs（计算光照贴图 UV）：为道路、交叉口和侧边对象生成光照贴图 UV。

    注意： Unity 将重建网格，导致顶点数不同。这意味着切换回编辑模式后所有交叉口需要重建。为在开发期间节省时间，可能希望保持此设置关闭。

  • Build LOD Groups（构建 LOD 组）：（未激活）为每条道路生成 LOD 组。
  • Build Terrain(s)（构建地形）：开始构建过程。您将看到进度条。该进度条尚未完全优化，可能看起来没有反应。特别是有大量树木和细节对象的场景可能需要一些时间。
  • Finalize Road Network（定稿道路网络）：从所有道路网络对象移除所有脚本组件。仅在道路网络所有工作完成后使用此选项。建议先在项目文件夹中复制场景，并将此场景保留为备份，以防实际需要对道路网络进行更改。此定稿选项特别适用于仅涉及侧边对象或使用不需要地形变形的自定义道路形状的情况。此定稿选项在下文介绍的构建模式中也可用。

地形构建过程完成后，Inspector 将更新：

  • Raise Road Network（抬升道路网络）：将道路网络移到地形上方更高处，以避免与地形发生 z-fighting。
  • Back to Edit Mode（返回编辑模式）：点击此按钮切换回编辑模式以继续处理道路网络。
  • Export Road Network Geometry（导出道路网络几何体）：将完整道路网络导出为 .obj。如果要在建模应用程序中手动为道路网络添加细节，这很有用。

    注意： 在较新的 Unity 版本中可以导出为 FBX。从 Package Manager 导入额外的 FBX Exporter 包，它会在 GameObject > Export To FBX 中添加 FBX 导出选项。取消勾选"Export Unrendered"。

EasyRoad3D-工具栏

概述

在 v3 中，所有 EasyRoads3D 功能都可以在 Inspector（检查器）中通过主 EasyRoads3D 工具栏访问，该工具栏在层级窗口（Hierarchy）中选中主道路网络游戏对象后显示。

工具栏选项卡

下面简要说明各工具栏选项卡。

Scene Status（场景状态）

此选项卡显示所选道路对象或连接/交叉口对象的属性。

Add New Road（添加新道路）

激活此选项卡以创建新道路。建议使用**道路类型（road types）**来工作。这可以省去为每条道路单独配置的时间，场景更易于管理，而且道路捕捉功能也依赖于道路类型。

新道路的道路类型可以从下拉菜单中选择，新道路将继承所选道路类型的所有设置。点击 “Add new Object”（添加新对象） 按钮后，新的道路游戏对象将在层级窗口中创建。按住 SHIFT 键并在场景中道路起点位置左键点击，即可添加标记控制点。添加两个标记后道路将显示出来。

Add Crossing Prefab（添加交叉口预制体）

此选项卡显示所有可用的交叉口/连接预制体。从列表中选择一个交叉口预制体，按住 SHIFT 键并在场景中点击交叉口应放置的位置。在此阶段，只要不进行其他操作，可以重复此操作以在不同位置实例化同一个交叉口对象。

当选中一条道路时，此选项卡将只显示匹配的交叉口/连接预制体。预制体将附加到所选标记上。

Build Terrain（构建地形）

此选项卡打开地形控制选项，用于根据道路网络的形状调整地形。

General Settings（常规设置）

常规设置选项卡包含多种选项，可帮助改进整体工作流程。您可以创建新的道路类型预设、交叉口对象并设置默认材质。在这里您还可以创建地形备份、恢复地形，以及通过导入 OSM 或 KML 数据源自动创建道路网络。

Side Objects（侧边对象）

此选项卡显示侧边对象管理器。使用它来创建新的侧边对象或编辑现有侧边对象。

Help / Info（帮助/信息）

帮助选项卡提供所导入 EasyRoads3D 版本的快速信息，以及一个 Help 按钮，点击后将从服务器打开本手册。

EasyRoad3D-故障排除

Shift + 点击添加道路标记不起作用，反而选中了地形

免费版发生这种情况时，是因为免费版不支持场景中的多个地形瓦片。在这种情况下，在当前未被 Terrain.activeTerrain 引用的地形上添加标记会失败。

Shift + 点击不起作用也可能发生在较新的 Unity 版本中，通常是自定义的 Unity 编辑器布局导致 OnSceneView() 不再捕获键盘或鼠标按钮事件，而是选中了被点击的对象（此处为地形）。

一个已知的原因是"Gizmos"选项卡（场景视图窗口右上方）未启用。无论如何，启用 Gizmos 是显示各种道路网络相关手柄所必需的，默认 Unity 设置中是启用的。

验证 Unity 编辑器状态的一种方法是复制项目，并通过主菜单 > Window > Layouts 将 Unity 编辑器布局重置为预设之一，之后可以再次自定义到偏好的布局。如果问题复现，请联系我们。我们已与 Unity QA 团队讨论过此事，他们见过这种情况，很希望了解如何复现此问题。

导入演示包后没有道路类型和侧边对象

演示包本身没有将道路类型和侧边对象数据存储在项目文件夹中。原因是稍后导入包更新时会覆盖这些数据，包括可能已更改的道路类型、侧边对象和新添加的道路类型、侧边对象。

要使道路类型和侧边对象在其他场景中可用，请打开演示场景，在层级中选择道路网络对象然后取消选择。此时项目道路类型、侧边对象数据将更新。道路类型和侧边对象现在将在其他场景中可用。

从 v3.1.9f0 开始，应该会有通知提示有新的道路类型和侧边对象预设可用，并提供将这些预设导入项目的选项。之后这些预设将在"常规设置 > 道路类型 > Add Project Road Types"和"侧边对象管理器 > Add Project Side Objects"中可用。

环岛未正确实例化和连接到道路的首/末标记

目前避免将环岛直接实例化到所选道路的第一个或最后一个标记。改用另一种方式在场景中实例化交叉口：选择交叉口预制体选项卡 。从可用交叉口预制体列表中选择环岛，按住 SHIFT 键并在场景中点击要放置环岛的位置。现在可以将道路连接到预制体，或通过拖动红色环岛连接手柄开始新道路。[完整信息见交叉口章节]。

更改半径、分辨率或添加/更改连接后环岛几何不更新

在创建/添加环岛连接之前，建议先正确设置半径和分辨率。可能的连接数量取决于分辨率、半径和连接宽度。当连接已存在时更改半径或分辨率，可能导致连接无法重建。发生时控制台会显示警告信息。可以尝试从连接 1 开始重新定位连接，仔细检查白色中间手柄和外侧绿色手柄的位置。当连接无法创建时（因为太靠近环岛起点或终点（固定位置的白色外侧手柄），或与另一个连接重叠），绿色手柄会变红。但最简单的解决方法是先移除所有连接，然后重新开始添加新连接，环岛几何将重建。

这将进一步优化。目前建议通过先正确设置半径和分辨率来避免这种情况。在这种情况下，只有当当前所选连接与另一个连接重叠时环岛几何才不重建。可以通过位置滑块更改其位置或更改连接宽度来修复。

激活/停用连接预制体上的人行道后，已连接道路的人行道不更新

当道路两端都连接到连接预制体时会发生。此问题将修复。目前请检查相应道路一侧的另一个连接人行道设置，确保它们匹配。

地形边界外的道路标记无法选择

当标记因某种原因位于地形边界外时，可以通过沿道路网格小心地向标记移动来选择它。

道路无法附加到交叉口连接，道路几何与交叉口连接几何匹配但中心连接手柄显示为红色

当人行道激活但外侧人行道手柄被禁用（意味着附加道路的人行道将不激活）时会发生。[选择特定交叉口]，确保该侧道路包含人行道时外侧拐角手柄为绿色（激活）。
