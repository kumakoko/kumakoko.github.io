Unity asset bundle的打标签规则

Unity asset bundle的打标签规则

构建unity assetbundle 资源包时，碰到了以下的编译问题：

Cannot mark assets and scenes in one AssetBundle. AssetBundle name is “scenes/map/fb_bossrush_01”.使用Unity打assetbundle包出了这个问题，是不是打assetbundle标签规则有问题

✅ 确实是AB标签规则违反Unity硬性限制：

同一个AssetBundle包，只能二选一：要么全是普通资源(prefab/texture/material等)，要么全是.unity场景文件，不能混在一起。

你的报错包名：scenes/map/fb_bossrush_01 说明这个ab包里，同时存在 .unity场景文件 + 普通资源文件。

产生这个错误的3种常见原因

1）文件夹直接设置了AB包名（最高频）

你把整个文件夹 scenes/map/ 的Inspector底部设置了AB包名 scenes/map/fb_bossrush_01。 文件夹打AB标签 = 文件夹下所有子文件全部归入这个ab。

  • 如果文件夹里：既有 fb_bossrush_01.unity（场景），又有prefab/mat/texture等普通资源 → 直接触发报错。

⚠️坑：文件夹设置ab标签，哪怕子文件单独改了标签，仍然会继承文件夹的ab设置。

2）手动给多个不同类型资源设置同一个ab包名

  • 场景文件 fb_bossrush_01.unity 设置ab=scenes/map/fb_bossrush_01
  • 同时这个目录下某个prefab/贴图也手动设置成同一个ab名字。 场景文件与普通资源共用同一个ab名称，报错。

3）代码批量赋值AB标签逻辑bug

编辑器脚本遍历目录，给目录下所有文件统一设置ab name，没有区分.unity场景文件，场景和普通资源被分配到同一个ab。

快速定位问题资源

  1. Project窗口搜索框输入：b:scenes/map/fb_bossrush_01

b: 是UnityProject窗口搜索语法，筛选所有标记为此ab包名的资源，会列出所有被打上这个ab标签的文件，一眼看哪些是.unity场景、哪些是普通资源。

  1. 检查父文件夹：选中搜索结果的父文件夹，看Inspector底部AB包名，很多时候是文件夹被设置了ab，不是单个文件。

修复方案

方案A：场景单独一个AB包（推荐）

  1. 场景文件 fb_bossrush_01.unity：ab标签设置为 scenes/map/fb_bossrush_01（这个包只能放这一个场景）
  2. 同目录下的prefab、贴图、材质不能再使用这个ab包名，分到别的ab包。

💡注意：场景AB包会自动把场景引用到的贴图、模型打进包内，不需要你手动把这些资源打上这个ab标签；手动打就会报错。

方案B：不要给文件夹设置AB标签

不要直接选中文件夹设置ab name，只给单个文件设置ab标签。文件夹设置ab标签极易出现场景与资源混杂。

方案C：代码打包场景请使用专用API

  • 普通资源打包：BuildPipeline.BuildAssetBundles()
  • 场景必须使用 BuildPipeline.BuildStreamedSceneAssetBundle()，不要把场景文件混到普通BuildAssetBundles流程里。

关键规则小结

  1. ❌禁止：1个ab包同时包含.unity场景和普通资源(prefab/texture/material)
  2. ✅场景ab：只给场景文件打标签，依赖资源由Unity自动收集，不要手动把依赖资源打上该ab名
  3. ⚠️谨慎给文件夹设置ab标签，极易出现混杂；优先单个文件打标签
  4. 搜索语法b:xxx快速排查哪些资源归属某个ab包
